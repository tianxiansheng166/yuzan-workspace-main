## Confirmed gaps to fix

1. Remove fake/demo login, offline sessions, fixed token and fixed school fallback; use the existing auth API and the returned server identity. Keep the existing login presentation and show accessible retryable errors.
2. Make Today surface course-list failures distinctly from a legitimate empty catalog.
3. Isolate optional recommendations/statistics failures from the required course-detail read; do not invent zero metrics.
4. Map published media fields from the server's nested `activity.content` when top-level aliases are absent; never introduce a fixed playback URL.
5. Replace Growth's baked example values with authorized API-backed data while retaining the original page's distinct visual hierarchy. An unavailable endpoint must yield an explicit unavailable state, not sample scores/comments.
6. Implement and test T099 partial/all-blank submission without weakening auth, state transition, failed-upload, pending-save or idempotency protections.
7. Add regression coverage for dynamic route IDs and the failure/empty states above. Fixture tests remain labeled `TEST_FIXTURE_ONLY`; they do not count as real API or browser acceptance.
