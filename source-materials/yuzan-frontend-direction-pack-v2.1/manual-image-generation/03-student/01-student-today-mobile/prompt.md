# 生图提示词

## 项目与用途

本图为“语赞心声”援藏教育公益平台而生成。该平台面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作。本图作为学生今日学习移动端 390×844 设计参考稿。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 青稞绿/高原绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 明确禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片 / 卡片墙；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图；
- 暖黄色主导画面。

## 输出要求

- 本提示词只生成一张独立图片，不生成拼贴图；
- 页面/区域：学生今日学习移动端页面；
- 推荐尺寸：390×844；
- 推荐比例：9:19.5；
- 中文内容要具体、真实、可读，无 lorem ipsum；
- 画面展示可实现的 Web UI，不做纯概念海报；
- 图中不要写大量正文，动态文字最终由前端真实渲染；
- 不出现假学校、假学生和假公益数据。

## 具体描述

生成一张 390×844 移动端学生今日学习设计稿。

- 顶部深高原绿品牌区；
- 标题“沿着今天的路径，完成三步学习”；
- 显示日期、连续学习天数和离线资源状态；
- 主体是一条纵向学习路径，不是课程卡片网格；
- 三步：词语热身、朗读“高原上的春天”、用自己的话表达；
- 当前步骤有绿色路径光环，但不跳动；
- 底部“进入朗读任务”像设备启动控制，含红—金—绿进度轨迹和微型声波；
- 只保留一个主要 CTA；
- 字体适合小学生但不幼稚；
- 触控目标清晰；
- 不使用游戏彩带、积分金币和通用卡通人物。
