# 生图提示词

## 项目与用途

本图为“语赞心声”援藏教育公益平台而生成。该平台面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作。本图作为教师课程工作台 1440×960 设计参考稿。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 青稞绿/高原绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 明确禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片 / 卡片墙；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图；
- 暖黄色主导画面。

## 输出要求

- 本提示词只生成一张独立图片，不生成拼贴图；
- 页面/区域：教师课程工作台；
- 推荐尺寸：1440×960；
- 推荐比例：3:2；
- 中文内容要具体、真实、可读，无 lorem ipsum；
- 画面展示可实现的 Web UI，不做纯概念海报；
- 图中不要写大量正文，动态文字最终由前端真实渲染；
- 不出现假学校、假学生和假公益数据。

## 具体描述

生成一张 1440×960 的课程编辑工作台设计稿。

结构必须是：
- 左侧固定产品导航；
- 顶部当前学校、课程路径、预览和提交审核；
- 页面标题“高原上的春天”；
- 四步发布状态轨道：课程草稿、内容完善、教学审核、发布使用；
- 主工作区三栏：左侧课程结构树，中间编辑画布，右侧活动属性；
- 中间画布显示具体课程内容、本节目标、教学支持和离线资源；
- 底部有红—金—绿同步轨迹，显示“草稿已保存，等待同步”。

风格：
- 教师工具高效、稳定、专业；
- 自然白与细线分区；
- 公益红用于主要动作和当前课程；
- 高原绿用于内容完善、保存和同步；
- 不将每个字段做成卡片；
- 不使用玻璃、渐变大按钮、浮动卡片墙；
- 字体和密度适合真实长期使用。
