# 生图提示词

## 项目与用途

本图为“语赞心声”援藏教育公益平台而生成。该平台面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作。本图作为测评报告详情 1440×1000 设计参考稿。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 青稞绿/高原绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 明确禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片 / 卡片墙；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图；
- 暖黄色主导画面。

## 输出要求

- 本提示词只生成一张独立图片，不生成拼贴图；
- 页面/区域：测评报告详情页面；
- 推荐尺寸：1440×1000；
- 推荐比例：7:5；
- 中文内容要具体、真实、可读，无 lorem ipsum；
- 画面展示可实现的 Web UI，不做纯概念海报；
- 图中不要写大量正文，动态文字最终由前端真实渲染；
- 不出现假学校、假学生和假公益数据。

## 具体描述

生成一张 1440×1000 的报告页面。

- 页首为深高原红到深高原绿的短色带与等高线；
- 标题“你的声音已经形成一条新的成长路径”；
- 主区显示一个克制的总体结果、文字结论、发音准确、朗读流利、句子节奏、表达完整四条能力线；
- 不使用一排 KPI 卡片；
- 右侧为“今天、本周、两周后”的建议时间轴；
- 下面可以展示具体语音证据、教师反馈和复测入口；
- 解释结果，不做医学诊断；
- AI 结论标注置信边界；
- 报告像成长叙事，不像商业仪表盘。
