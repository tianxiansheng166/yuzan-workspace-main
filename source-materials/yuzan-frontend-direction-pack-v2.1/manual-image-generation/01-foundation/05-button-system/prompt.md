# 生图提示词

## 项目与用途

本图为“语赞心声”援藏教育公益平台而生成。该平台面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作。本图作为全站按钮系统设计参考稿。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 青稞绿/高原绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 明确禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片 / 卡片墙；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图；
- 暖黄色主导画面。

## 输出要求

- 本提示词只生成一张独立图片，不生成拼贴图；
- 页面/区域：按钮系统设计板；
- 推荐尺寸：1440×1100；
- 推荐比例：4:3；
- 中文内容要具体、真实、可读，无 lorem ipsum；
- 画面展示可实现的 Web UI，不做纯概念海报；
- 图中不要写大量正文，动态文字最终由前端真实渲染；
- 不出现假学校、假学生和假公益数据。

## 具体描述

生成一张独立的 1440×1100 组件设计板，展示 12 个具体按钮及状态。

必须包含：进入学习路径、开始朗读、停止录音、完成并继续、发布教学任务、保存到本机、等待同步、同步失败后重试、提交审核、发布反馈、返回上一步、不可用状态。

交互设计：
- 使用路径线、节点、声波、扫描光带或结构收束表达状态；
- 按下后路径推进、节点锁定、文本切换；
- loading 不使用无限旋转圆圈；
- 不做整个按钮轻微上浮；
- 不做跳动、抖动和霓虹；
- 公益红、高原绿、深岩石、藏式蓝四类；
- 每个按钮展示默认、hover/focus、pressed、loading/offline/disabled 的关键状态；
- 必须是可实现的 HTML/CSS/SVG 组件，不是纯美术按钮图片。
