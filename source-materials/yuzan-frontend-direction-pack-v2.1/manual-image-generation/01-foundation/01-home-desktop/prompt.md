# 生图提示词

## 项目与用途

本图为“语赞心声”援藏教育公益平台而生成。该平台面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作。本图作为首页桌面端 1440×1024 设计参考稿。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 青稞绿/高原绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 明确禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片 / 卡片墙；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图；
- 暖黄色主导画面。

## 输出要求

- 本提示词只生成一张独立图片，不生成拼贴图；
- 页面/区域：首页桌面端完整页面；
- 推荐尺寸：1440×1024；
- 推荐比例：16:10；
- 中文内容要具体、真实、可读，无 lorem ipsum；
- 画面展示可实现的 Web UI，不做纯概念海报；
- 图中不要写大量正文，动态文字最终由前端真实渲染；
- 不出现假学校、假学生和假公益数据。

## 具体描述

生成一张独立的 1440×1024 高保真 Web 首页设计稿。

产品：语赞心声，面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作的援藏教育公益平台。

首屏构图：
- 顶部自然白实色导航，左侧旧项目橙红 Logo 与“语赞心声”；
- 导航：学习课程、智能测评、教师资源、公益与志愿；
- 右侧“教师工作台”和公益红“开始学习”；
- 首屏左侧为使命文案：“让每一次发声，沿着高原的学习路径被听见”；
- 右侧不是 UI 卡片，而是原创红色山脊、绿色谷地、金色太阳、等高线和声波形成的艺术构图；
- 背景从深高原红自然过渡到深高原绿，不要紫蓝；
- 三个入口按钮采用公益红、成长绿和深岩石色。

首屏以下：
- 用一条横向红—金—绿学习路径表达“能力诊断 → 分级课程 → 教师任务 → 学生练习 → 反馈复测 → 成长报告”；
- 下一段采用红绿分屏，解释学生、当地教师、志愿者和学校管理之间的长期协作；
- 不使用三张入口卡片和四张价值卡片；
- 留白、编辑式排版、中文衬线标题；
- 真实产品感，不显示设计系统、开发预览、模块状态。

要有艺术感、文化温度和明确的信息层级，但必须可被 Nuxt/Vue 实现。
