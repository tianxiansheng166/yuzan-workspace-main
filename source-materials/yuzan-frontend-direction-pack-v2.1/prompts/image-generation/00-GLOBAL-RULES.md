# 生图总规则

所有图必须服务于“语赞心声”援藏教育公益平台，不是通用 AI SaaS。

## 统一视觉基因

- 主题：红脉青稞 · 高原声场；
- 公益红/高原红：使命、连接、主要行动；
- 高原绿/青稞绿：成长、课程、教师支持、离线稳定；
- 藏式蓝：语言、信息和测评辅助；
- 高原金：路径节点、文化细节；
- 雪山白/自然白：主要产品画布；
- 母题：红色山脊、绿色谷地、等高线、学习路径、语言声波；
- 气质：克制、可信、尊重、清晰、有文化温度、现代编辑式。

## 禁止

- 紫蓝霓虹科技渐变；
- 玻璃拟态；
- 一排排相同卡片；
- 巨大黑体字压满画面；
- 3D 光球、宇宙、机器人脑袋；
- 旅游海报式雪山、寺庙、经幡堆砌；
- 未授权儿童照片或写实人物；
- 假学校、假公益数字、假合作单位；
- emoji 图标；
- 按钮整体轻微上浮作为主要交互；
- 将页面全部文字烘焙进背景图。

## 输出

页面设计稿：

- 独立页面单图，不拼版；
- 桌面优先 1440×900 或 1440×1024；
- 移动优先 390×844；
- 中文内容要具体、真实、可读；
- 页面状态和数据要与业务一致；
- 不出现 lorem ipsum；
- 画面要展示可实现的 Web UI，不做纯概念海报。

背景/封面/纹理：

- 默认不带文字；
- 给出无文字安全区；
- 可裁切；
- 可做 SVG/PNG/WebP；
- 需要低带宽静态版；
- 不依赖照片和外链资源。

## 使用方式

将页面 Prompt 与对应的资产 Prompt 分开生成。页面图用于构图参考，资产图用于真正进入前端。不要把页面设计稿直接作为网页背景。
