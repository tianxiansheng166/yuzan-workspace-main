# 登录与学校选择页面

生成一张 1440×900 的登录页面设计稿和一张 1440×900 的学校选择页面设计稿，分别输出。

登录页：
- 左侧约 44% 为深高原红到深高原绿的品牌艺术区，包含地形线、声波和一句援藏教育使命；
- 右侧自然白登录区，表单简洁、标签始终可见；
- 不使用玻璃卡片；
- 错误、加载、网络不可用提示真实；
- 登录按钮公益红，设备/弱网提示高原绿；
- 不让用户先选择角色，角色由账户决定。

学校选择页：
- 顶部说明“选择本次工作的学校”；
- 学校对象使用紧凑的可选择业务行，而不是巨大卡片；
- 显示角色、班级数量和最近同步；
- 单学校可直接继续，多学校需要明确选择；
- 右侧有一条纵向学习/支持路径艺术线；
- 保持自然白画布和红绿品牌关系。
