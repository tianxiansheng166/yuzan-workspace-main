# 定制图标系统

生成一张 1440×900 的 32 枚图标设计板。

图标主题：
- 学习路径；
- 课程；
- 朗读；
- 录音；
- 声波；
- 书面练习；
- 教师任务；
- 提交复核；
- 成长报告；
- 学校；
- 班级；
- 志愿支持；
- 离线下载；
- 等待同步；
- 同步成功；
- 同步失败；
- 隐私；
- 权限；
- 藏汉翻译；
- 思维教学工具等。

风格：
- 2px 几何线条；
- 方圆结合；
- 路径节点、等高线和声波形成统一识别；
- 不使用 emoji；
- 不复制常见 Material/Lucide 外形；
- 红、绿、蓝、金可作为状态点，但图标单色也能辨认；
- 输出适合转成 SVG sprite。
