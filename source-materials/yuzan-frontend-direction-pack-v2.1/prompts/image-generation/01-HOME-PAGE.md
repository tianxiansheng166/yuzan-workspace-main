# 首页完整页面设计稿

生成一张独立的 1440×1024 高保真 Web 首页设计稿。

产品：语赞心声，面向西藏农牧区国家通用语言学习、当地教师支持、学生成长和志愿协作的援藏教育公益平台。

首屏构图：
- 顶部自然白实色导航，左侧旧项目橙红 Logo 与“语赞心声”；
- 导航：学习课程、智能测评、教师资源、公益与志愿；
- 右侧“教师工作台”和公益红“开始学习”；
- 首屏左侧为使命文案：“让每一次发声，沿着高原的学习路径被听见”；
- 右侧不是 UI 卡片，而是原创红色山脊、绿色谷地、金色太阳、等高线和声波形成的艺术构图；
- 背景从深高原红自然过渡到深高原绿，不要紫蓝；
- 三个入口按钮采用公益红、成长绿和深岩石色。

首屏以下：
- 用一条横向红—金—绿学习路径表达“能力诊断 → 分级课程 → 教师任务 → 学生练习 → 反馈复测 → 成长报告”；
- 下一段采用红绿分屏，解释学生、当地教师、志愿者和学校管理之间的长期协作；
- 不使用三张入口卡片和四张价值卡片；
- 留白、编辑式排版、中文衬线标题；
- 真实产品感，不显示设计系统、开发预览、模块状态。

要有艺术感、文化温度和明确的信息层级，但必须可被 Nuxt/Vue 实现。
