# 前端完成定义

## 1. 视觉方向

- 旧项目红、绿、蓝、金和雪山白可辨认；
- 页面明确表达援藏教育公益；
- 不像通用 AI SaaS；
- 暖黄色不再统治全站；
- 玻璃拟态已移除；
- 首页不是卡片墙；
- 功能页采用适合任务的结构；
- 所有页面属于同一个品牌系统。

## 2. 页面证据

必须提供：

- 390×844；
- 768×1024；
- 1440×900。

关键路由全部截图。

首页提供完整长页截图。

## 3. 交互

- 键盘可访问；
- 焦点可见；
- 对话框焦点管理；
- 移动菜单可用；
- 200% 缩放无关键内容丢失；
- 无横向溢出；
- 触控目标至少 44px；
- reduced motion 可用；
- 状态不只靠颜色。

## 4. 工程

- tests passed；
- typecheck passed；
- build passed；
- 无 hydration mismatch；
- 无 console error；
- 无静态资源 404；
- 无外链视觉资源；
- 无敏感数据；
- worktree clean；
- 普通 push；
- 不修改业务契约。

## 5. 视觉评分

每项 0–5：

| 项目 | 最低通过 |
|---|---:|
| 援藏公益识别度 | 4 |
| 旧品牌延续 | 4 |
| 页面结构 | 4 |
| 非模板感 | 4 |
| 教师工作效率 | 4 |
| 学生易用性 | 4 |
| 响应式 | 4 |
| 可访问性 | 4 |
| 动效质量 | 3 |
| 弱网性能 | 4 |

总分不得低于 40/50。

## 6. 一票否决

- 首页仍是卡片墙；
- 全站仍是米黄；
- 导航仍使用 `backdrop-filter`；
- 显示内部研发语言；
- 使用假公益数据；
- 使用未授权人物图；
- 页面互相像不同产品；
- 为视觉破坏真实业务状态；
- 登录或写操作用假成功掩盖后端不可用。
