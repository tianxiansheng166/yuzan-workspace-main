# 布局与组件规则

## 1. 页面网格

- 最大内容宽度：1440px；
- 标准工作区：1200–1320px；
- 阅读列：680–760px；
- 页面边距：移动 16px，平板 24px，桌面 40–64px；
- 使用 12 列网格；
- 主内容和辅助面板比例常用 8/4、9/3、7/5；
- 不把所有区块都放在相同宽度的居中容器中。

## 2. 导航

### 公共导航

- 雪山白实色背景；
- 红色细线或短下划线表示当前项；
- Logo、核心入口、角色入口和登录；
- 不显示开发预览、路由状态和组件状态；
- 不使用模糊玻璃。

### 产品导航

桌面：

- 左侧窄导航或顶部 + 左侧组合；
- 当前角色与学校清晰；
- 教师、学生、管理员只看到自己的导航；
- 主要操作不放在导航底部漂浮。

移动：

- 顶部品牌栏；
- 底部 3–5 个主入口或抽屉；
- 不能把桌面侧栏简单横向缩小。

## 3. 卡片使用合同

允许使用卡片：

- 一门课程；
- 一份作业；
- 一次提交；
- 一个报告；
- 一个需要选择的学校；
- 一个离线下载对象。

禁止使用卡片：

- 页面标题；
- 普通说明文字；
- 每一个设置项；
- 导航分组；
- 价值主张；
- 普通统计数字；
- 每一个表单区；
- 纯装饰内容。

卡片规则：

- 同屏主要卡片数量一般不超过 6；
- 移动端不要连续出现 8 个以上大卡片；
- 卡片内部不再嵌套完整卡片；
- 状态用标签、行内提示或侧边条；
- 阴影极少；
- 优先用列表项和分隔线。

## 4. 表格与列表

教师端和管理端优先：

- 表格；
- 带摘要的列表；
- 行内操作；
- 批量选择；
- 侧边详情；
- 可保存筛选；
- 空状态和错误状态。

移动端将表格转换为“摘要行 + 展开详情”，不是将每行变成巨大卡片。

## 5. 表单

- 标签始终可见；
- 输入说明和错误分开；
- 主要按钮只保留一个；
- 保存状态明确；
- 长表单采用步骤或分区；
- 课程编辑使用左侧结构树 + 中间编辑 + 右侧属性；
- 作业发布使用步骤流；
- 学生作答使用单任务聚焦。

## 6. 数据可视化

- 图表必须能解释教学问题；
- 不以装饰圆环代替真实分析；
- 同一页面不超过 3 种图表；
- 图表旁提供文字结论；
- 颜色不作为唯一编码；
- 高原绿表示成长，藏式蓝表示能力结构，红色表示需要关注；
- 不用 3D 图表。

## 7. 状态组件

必须支持：

- 未开始；
- 进行中；
- 待同步；
- 已完成；
- 需要复核；
- 同步失败；
- 服务不可用；
- 权限不足。

每个状态包含：

- 文本；
- 图形或结构差异；
- 可选颜色；
- 下一步行动。
