# 品牌系统

## 1. 最终色板

下面的色值在旧项目基础上现代化，并保证常用文字组合达到 WCAG AA。

### 品牌红

| Token | 色值 | 用途 |
|---|---:|---|
| `red-950` | `#5B1721` | 深色首屏、深色导航、文字 |
| `red-850` | `#74212C` | 深品牌面 |
| `red-700` | `#9D2933` | 旧项目核心红、主要按钮 |
| `red-600` | `#A33A45` | 悬停、辅助强调 |
| `red-100` | `#F4E4E4` | 轻背景，不作为整页画布 |

### 高原绿

| Token | 色值 | 用途 |
|---|---:|---|

| `green-650` | `#4E765B` | 成长与进度 |
| `green-500` | `#5B8C5A` | 旧项目青稞绿，只用于大字或图形 |
| `green-100` | `#E1EBE2` | 轻状态面 |

## 2. 使用比例

公共页面建议：

```text
雪山白/自然白 55%
公益红/高原红 20%
高原绿 12%
岩石中性色 8%
藏式蓝、金色、橙色 5%
```

工作台建议：

```text
自然白和中性色 75%
红色 10%
绿色 8%
蓝/金/橙 7%
```

## 3. 禁止的颜色用法

- 红绿 50/50 高饱和对撞；
- 全站暖黄；
- 金色做大面积渐变；
- 蓝紫霓虹；
- 低对比浅灰文字；
- 用绿色表示所有成功、红色表示所有失败而没有文字或图标；
- 在教师工作台大面积使用深红背景。

## 4. 字体

### 公共页面标题

优先：

```css
"Source Han Serif SC", "Noto Serif SC", "Songti SC", serif
```

用途：

- 品牌名；
- 公共首屏；
- 使命标题；
- 公益和文化叙事。

### 产品界面

优先：

```css
"Noto Sans SC", "Microsoft YaHei", "PingFang SC", system-ui, sans-serif
```

用途：

- 导航；
- 表单；
- 表格；
- 学习界面；
- 数据和状态。

### 字号

| 场景 | 桌面 | 移动 |
|---|---:|---:|
| 公共首屏标题 | 56–72px | 38–48px |
| 页面标题 | 36–48px | 28–36px |
| 区块标题 | 28–36px | 24–30px |
| 正文 | 16–18px | 16–18px |
| 辅助文字 | 14px | 14px |

禁止用 96px 以上标题作为默认方案。

## 5. 圆角与阴影

- 普通控件：8px；
- 独立业务对象：10–14px；
- 对话框：14px；
- 不使用 24–32px 超大圆角作为默认；
- 阴影只用于浮层和明确悬浮对象；
- 页面分区优先使用背景、线条和排版，不使用阴影。

## 6. Logo

旧 Logo 可以继续使用，但需要：

- 生成适配深色、浅色、单色的版本；
- 不拉伸；
- 保留安全边距；
- 导航中的 Logo 高度控制在 28–36px；
- 公共首屏不重复放大 Logo；
- 未来可在不改变核心识别的前提下做矢量化和细节修复。
