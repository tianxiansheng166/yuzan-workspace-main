# 优秀案例与 Prompt 方法研究

## 1. MotionSites 方法

MotionSites 公开定位是面向 Lovable、Bolt、Cursor、Claude 等工具的网站 Prompt、模板、区块和动画库。其核心价值不是某个固定模板，而是：

```text
视觉参考
+ 明确的艺术方向
+ 页面结构
+ 动效分镜
+ 技术栈
+ 禁止项
+ 可交付结果
```

本设计包不复制其付费 Prompt 原文，而是采用同类“设计系统用语言表达”的方法，编写针对语赞心声的原创执行 Prompt。

## 2. 可借鉴的非营利组织案例

### charity: water

可借鉴：

- 使命先于功能；
- 首屏直接说明改变什么；
- 行动号召清晰；
- 用故事、影响和参与路径组织页面；
- 色彩承担品牌识别而不是仅承担状态。

不可照搬：

- 强募捐导向；
- 高强度影像依赖；
- 不适合弱网的媒体密度。

### The Ocean Cleanup

可借鉴：

- 把复杂问题压缩成一句明确目标；
- 使用路径、进度和技术过程构建叙事；
- 大区块留白和可视化结构；
- 信息层次强，卡片使用克制。

不可照搬：

- 科技蓝和工程品牌风格；
- 大规模视频与三维资产。

### Teach For All

可借鉴：

- 教育使命与本地网络并重；
- 展示“人—学校—区域—共同目标”的关系；
- 以故事、网络和实践而不是纯产品功能组织内容。

不可照搬：

- 国际 NGO 的全球化视觉；
- 与中国援藏教育语境不匹配的文案。

## 3. 适用于本项目的 Prompt 结构

所有前端 Prompt 应按下面顺序：

1. **身份**：你是产品设计师、动效设计师和 Nuxt 工程师；
2. **使命**：为援藏教育公益平台设计，而不是 SaaS；
3. **受众**：学生、当地教师、志愿者、学校管理者；
4. **遗产**：继承旧项目红、绿、蓝、金、雪山白和 Logo；
5. **视觉概念**：红脉、青稞路径、高原声场；
6. **页面构图**：明确每个区块，不说“做得高级”；
7. **动效分镜**：进入、滚动、交互和退出；
8. **技术约束**：Nuxt、SSR、弱网、可访问、性能；
9. **禁止项**：卡片墙、玻璃、紫蓝、假数据、通用 SVG；
10. **交付物**：代码、测试、截图、资产登记；
11. **验收**：视觉、响应式、交互和性能标准；
12. **迭代**：先开发完整波次，再统一评审修正。

## 4. 本项目应该达到的“高级感”

不是：

- 所有内容居中；
- 每个信息一个卡片；
- 大字号 + 渐变；
- 一堆漂浮装饰；
- 动画越多越高级。

而是：

- 使命明确；
- 视觉母题一致；
- 版式有节奏；
- 信息密度与角色任务匹配；
- 红绿关系克制；
- 动效能解释路径和状态；
- 弱网仍然可用；
- 每个页面看起来属于同一个真实产品。
