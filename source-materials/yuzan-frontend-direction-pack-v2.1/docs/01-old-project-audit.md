# 旧项目视觉审计

## 1. 旧项目真实定位

旧仓库将项目描述为“面向西藏农牧区国家通用语言文字学习”的智慧教育平台。首页不仅包含课程，还包含：

- 分级课程；
- 文化融合教学；
- 公益反哺；
- 离线学习；
- AI 语音评测；
- 教师、学生、学校管理员和志愿者协同；
- “守护心声”结对帮扶；
- 公益基金和教师资源库。

因此，旧项目最重要的资产不是某个按钮样式，而是完整的产品叙事：

```text
援藏教育使命
→ 国家通用语言学习
→ 本地教师支持
→ 学生持续成长
→ 志愿者长期陪伴
→ 弱网与离线保障
```

## 3. 旧项目可继承的视觉基因

### 必须继承

- 红色是使命主色，而不是仅用于错误或小按钮；
- 绿色代表成长、青稞、课程路径和教师支持；
- 金色只做 Logo、路径节点和文化细节；
- 雪山白或自然白作为主内容底色；
- 红色山脊、层叠高原、地形线、声波可作为品牌母题；
- 首页必须直接表达援藏教育与公益支持；
- 导航要保留“教师资源”“公益/志愿支持”的产品位置；
- 公共页面和产品工作台需要明显区分。

### 可以创新

- 旧项目过度依赖 Tailwind 卡片和阴影；
- 首屏文字过大；
- 课程筛选在移动端变成长列表；
- 外链背景图片和 Font Awesome 不应继续使用；
- 假指标、假学校和假合作伙伴不能进入新产品；
- 红色与绿色需要更现代、更克制的饱和度；
- 旧页面中大量圆角、卡片和浮动按钮需要简化；
- 藏文化表达应尊重真实内容，不能堆砌旅游符号。

## 4. 当前新项目的偏差

当前新项目 Token 将 `#F7F2E8` 和 `#EFE4D2` 设为全站画布，导致：

- 红色和绿色从品牌主色退化为局部强调；
- 页面整体接近米黄生活方式网站；
- 公益使命和高原文化辨识度下降；
- 多个页面采用大圆角卡片 + 大黑体字；
- 视觉更像通用 AI/SaaS 模板；
- 应用壳出现玻璃拟态和内部研发语言。

## 6. 继承矩阵

| 元素 | 保留 | 重做 |
|---|---|---|
| 公益红 | 保留核心语义 | 降低大面积高饱和冲击 |
| 青稞绿 | 保留成长语义 | 用于路径、状态和教师支持 |
| 藏式蓝 | 保留辅助语义 | 只用于信息和语言能力 |
| 高原金 | 保留 Logo/节点 | 不做大面积背景 |
| 红色山脊 | 保留构图基因 | 改成原创矢量/纹理 |
| 地形线 | 保留 | 与学习路径和音轨结合 |
| 卡片网格 | 不保留 | 改为编辑式分区、列表和路径 |
| 浮动圆形按钮 | 不保留 | 改为明确导航和工具栏 |
| 假公益数据 | 不保留 | 只显示真实数据或明确占位 |
| 外链图片 | 不保留 | 使用本地、原创、可追溯资源 |
