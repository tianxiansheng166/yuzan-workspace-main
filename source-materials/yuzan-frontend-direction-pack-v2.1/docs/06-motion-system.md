# 动效系统

## 1. 原则

动效必须解释：

- 路径；
- 层级；
- 进度；
- 状态变化；
- 角色之间的连接。

禁止用动效掩盖信息不足。

## 2. 公共页面动效

### 首屏

- 地形线缓慢显现：700–1000ms；
- 红色山脊和绿色路径只做轻微位移；
- 声波线从静态到低幅呼吸；
- CTA 在标题之后 100–160ms 出现；
- 不使用长时间自动循环的大幅动画。

### 滚动路径

- 节点进入视口时路径逐段绘制；
- 当前节点增强，其他节点保持静态；
- 不做滚动劫持；
- 不强制全屏翻页。

## 3. 工作台动效

- 页面切换：120–180ms；
- 侧栏展开：180–220ms；
- 保存成功：状态文本和细线变化；
- 拖拽排序：明确占位和落点；
- 表格排序/筛选：保持布局稳定；
- 禁止所有卡片悬浮上移。

## 4. 学生端动效

- 下一任务强调；
- 作答反馈简短；
- 录音声波实时但低成本；
- 离线保存后显示“已保存在本机，等待同步”；
- 不使用游戏化爆炸、彩带和高频闪烁。

## 5. 性能预算

- 首屏 JS 动效附加包尽量小于 35KB gzip；
- 优先 CSS transform/opacity；
- 避免大面积滤镜和 blur；
- 不在低端设备持续运行 Canvas；
- 图片使用响应式和本地资源；
- 弱网优先显示静态视觉；
- LCP 目标 < 2.5s；
- CLS 目标 < 0.1；
- 交互响应目标 < 200ms。

## 6. Reduced Motion

当 `prefers-reduced-motion: reduce`：

- 路径绘制立即完成；
- 取消视差；
- 取消自动循环；
- 保留状态变化；
- 所有过渡不超过 1ms 或直接关闭。
