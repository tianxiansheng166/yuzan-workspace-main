## 阶段1：基础加固（2-3周）

> 目标：堵住安全漏洞，数据层从JSON迁移到PostgreSQL

### 1.1 安全修复（3天）

| 任务 | 具体做法 |
|------|---------|
| JWT密钥 | 从环境变量读取，不硬编码；加 .env 到 .gitignore |
| CORS白名单 | 限制为项目域名 + localhost |
| 请求体限制 | `express.json({ limit: '1mb' })` |
| 文件上传安全 | 验证文件头魔数（不只看MIME）、病毒扫描 |
| 速率限制 | 所有API加全局限流 |
| HTTPS | 生产环境强制HTTPS |
| 日志系统 | 引入winston，结构化日志输出 |

### 1.2 数据库迁移（5-7天）

**从 JSON文件 → PostgreSQL**

```
当前：fs.readFileSync('db/users.json') → JSON.parse → 内存过滤
目标：pool.query('SELECT * FROM users WHERE id = $1', [id])
```

数据表设计（核心5张表）：

```sql
-- 用户表
users (id, username, phone, password_hash, role, level, school, region, dialect, avatar, created_at, updated_at)

-- 课程表
courses (id, title, description, theme, level, grade, dialect, cover_url, cultural_tags, tech_tags, research_tags, created_at)

-- 章节表
chapters (id, course_id, title, sort_order, video_url, subtitle_zh, subtitle_bo, duration)

-- 学习进度表
progress (id, user_id, course_id, chapter_id, progress_pct, video_position, growth_value, last_studied_at)

-- 学习行为表
learning_records (id, user_id, type, course_id, detail, duration, score, created_at)
```

迁移步骤：
1. 安装 `pg` + `dotenv`
2. 创建数据库和表结构
3. 写迁移脚本把 JSON 数据导入 PostgreSQL
4. 用 DAO 层封装数据库操作，替换 `readJSON/writeJSON`
5. 保留 JSON 文件作为 fallback，双写一段时间

### 2.3 Redis缓存

```javascript
// 热点数据缓存
async function getCourses(filters) {
  const cacheKey = `courses:${JSON.stringify(filters)}`;
  const cached = await redis.get(cacheKey);
  if (cached) return JSON.parse(cached);
  
  const courses = await CourseModel.find(filters);
  await redis.setex(cacheKey, 300, JSON.stringify(courses)); // 5分钟
  return courses;
}
```

| 个性化推荐 | 基于学习历史的课程推荐 | P2 |

### 3.2 藏语AI能力集成

**方案A（推荐）：接入智达AI/查瓦云API**
- 优势：不需要自己训模型，快速上线
- 成本：按调用量计费
- 路径：先API接入验证，后续考虑本地化

**方案B：部署HY-MT1.5离线翻译**
- 优势：离线可用，隐私安全
- 成本：需GPU服务器
- 路径：先云端部署，缓存常用翻译到本地

**语音评测方案：**
1. 学生朗读指定藏语文本
2. 录音上传→调用语音识别API（智达AI/查瓦云）
3. 将识别结果与标准文本对齐
4. 基于音素级对比生成评分（发音准确度/流利度/完整度）
5. 返回评分+改进建议+标准发音示范
