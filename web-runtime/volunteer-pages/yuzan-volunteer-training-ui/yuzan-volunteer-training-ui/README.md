# 语赞心声｜志愿者培训首页

独立、可直接运行的高保真前端还原，不依赖原项目。页面中的导航、课程、进度、资源下载、弹窗和按钮均由 HTML/CSS/JavaScript 实现；提供的插画仅作为独立装饰素材使用。

## 运行

直接双击 `index.html`，或在目录内启动静态服务器：

```bash
python -m http.server 4173
```

访问 `http://localhost:4173`。

## 浏览器校准

```bash
npm install
npm run screenshot
```

截图输出到 `qa/current.png`，默认视口为 1672×941。
