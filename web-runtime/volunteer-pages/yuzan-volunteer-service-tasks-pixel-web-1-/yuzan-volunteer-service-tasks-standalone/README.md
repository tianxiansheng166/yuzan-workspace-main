# 语赞心声｜志愿服务任务中心独立网页

本压缩包不写入原项目，解压后可直接运行。

## 打开

直接打开 `index.html`，或在目录中运行：

```bash
python -m http.server 8080
```

## 文件

- `index.html`：语义化页面结构
- `styles.css`：桌面、平板、移动端样式
- `app.js`：任务筛选、确认、服务记录和风险上报交互
- `assets/`：从用户素材中按页面职责裁切、降饱和、虚化和渐隐处理后的运行资产
- `reference/`：原始参考图、设计说明和补充图片，仅供校准，不参与页面布局

## 图片职责

- 顶部山景：只作为横向远景气氛层，采用超宽裁切、轻微虚化和渐隐。
- 左下山景：独立适配侧栏纵向区域，未与顶部图片共用缩放。
- 其余大图：保留在 reference 中，不为“放全图片”而强行塞进业务界面。
- Logo：仅提取图案，中文品牌文字由 HTML 渲染。
