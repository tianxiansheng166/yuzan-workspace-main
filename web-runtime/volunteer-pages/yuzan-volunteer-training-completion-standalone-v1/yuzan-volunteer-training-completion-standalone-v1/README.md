# 志愿者培训完成与资格｜独立网页

本目录是独立静态网页，不会写入原项目。

## 运行

直接打开 `index.html`。浏览器若限制本地文件，可在本目录执行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 资产使用

- 左上角图案：从用户提供的 Logo 中提取，仅保留原图案；品牌文字由 HTML 渲染。
- 右上角山脊：作为窄幅页眉远景，横向裁切、渐隐，不强行展示完整背景图。
- 左下角山景：仅用于侧栏底部装饰，真实按钮由 HTML 覆盖。
- 书本与绿植：作为“复盘与建议”的小型装饰图，不进入主要操作区。
- 用户额外提供的完整插画保留在 `assets/`，未为了“放全图片”强行塞入不适合的位置。

## 页面内容

培训完成路径、完成概览、复盘建议、服务资格、资格标准确认、下一步任务和底部三项主操作均使用 HTML/CSS 构建。
