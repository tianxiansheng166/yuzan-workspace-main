# 语赞心声｜一对一帮扶管理独立网页

这是一个不写入任何项目、解压即可运行的静态高保真页面。

## 打开方式

直接双击 `index.html`。若浏览器限制本地脚本，可运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 结构

- `index.html`：页面结构和内联 SVG 图标
- `styles.css`：桌面、平板与移动端响应式布局
- `app.js`：学生切换、流程切换、预约、风险标记、结束帮扶等交互
- `assets/logo-mark.png`：只保留用户提供 Logo 的图案部分，品牌文字使用 HTML 渲染
- `assets/hero-top.webp`：用户提供的右上角山水素材
- `assets/sidebar-art.webp`：用户提供的竖版山川素材裁切
- `assets/pairing-illustration.webp`：在操作弹窗内低调使用的帮扶主题装饰图
- `reference/`：原始参考图、提示词、说明及额外背景素材

## 实现边界

学生姓名、教师信息、帮扶状态、记录、预约和风险等均为网页文本与组件，不是整页位图，可继续替换为真实接口数据。


## 第二次视觉修正

- 使用低饱和、低对比、轻微虚化和左右/底部渐隐，减少与白色工作区的色差。
- 左下山景使用独立裁切，不再为了展示完整图片而压缩整张素材。
