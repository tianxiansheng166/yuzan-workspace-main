# 语赞心声｜测评内容配置中心（独立还原包）

本项目是独立静态网页还原，不会写入原项目。

## 文件
- `index.html`：真实 HTML 结构
- `styles.css`：页面视觉与响应式布局
- `app.js`：筛选、内容切换、编辑、预览、发布、关联任务、拖拽维度等交互
- `assets/`：独立 Logo 图案和低强度背景素材
- `qa/`：桌面端、平板端、移动端截图及视觉校准报告

## 运行
直接打开 `index.html`，或使用任意静态服务器运行。

## 实现边界
动态文字、按钮、筛选、表格、评分规则、版本信息、发布状态均由 HTML/CSS/JavaScript 渲染；没有将整张参考图作为网页背景。Logo 只使用图案，品牌文字由真实文本排版。
