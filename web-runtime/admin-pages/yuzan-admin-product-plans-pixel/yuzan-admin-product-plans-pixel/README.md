# 商业套餐管理 - 静态还原包

## 运行方式

直接打开 `index.html`，或在当前目录执行本地静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：基础交互
- `assets/`：Logo 图案、山脉背景、封面素材
- `qa/`：运行截图、参考对比图、差异图

## 说明

- 页面为独立静态还原包，没有写入原项目。
- 导航、搜索框、表单、表格、按钮、状态标签均为真实 HTML/CSS/JS。
- 背景山脉与封面图为独立素材，没有把整张参考图直接作为网页底图。
