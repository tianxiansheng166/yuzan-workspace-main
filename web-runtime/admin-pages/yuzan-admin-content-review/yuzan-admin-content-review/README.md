# 内容审核工作台

独立交付包，未写入任何现有项目。

## 内容
- `index.html`：页面入口
- `styles.css`：样式文件
- `app.js`：交互逻辑
- `assets/`：Logo 图案与背景/预览素材
- `qa/`：参考图、截图、差异图与简单报告

## 设计与实现说明
- Logo 仅使用图案部分，品牌文字改为前端文本。
- 左侧为审核队列，中间为证据画布，右侧为结构化审核反馈，底部为审批动作区。
- 动态区域均以 HTML/CSS/JS 重建，没有将整张参考图直接作为网页背景。
- 背景图被拆分为顶部山脊横幅、内容预览插画及低透明装饰层，并做了淡化与混合处理。
- 包含桌面、平板、手机三档响应式布局。
