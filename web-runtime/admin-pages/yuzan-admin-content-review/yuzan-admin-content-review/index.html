课程目录（18）

1.1 高原生态系统的特征

青藏高原海拔高、太阳辐射强、昼夜温差大，形成了独特的高原生态系统。平均海拔超过 4000 米以上，空气稀薄、蒸发量大，降水分布不均，是学习“环境适应”与“生态脆弱性”的基础案例。

主要特征包括：① 生物多样性丰富；② 生态系统脆弱；③ 生产力较低；④ 对气候变化敏感。文本整体准确，但“生产力较低”的表述建议补充生活化例子，降低理解门槛。
