# 路由与主要交互

| 路由 | 页面 | 主要交互 |
|---|---|---|
| `/` | 公共首页 | 导航、学习入口、教师入口、学习路径弹窗 |
| `/login` | 登录 | 自定义校验、密码显示、登录状态、离线提示 |
| `/select-school` | 学校选择 | 学校与身份切换、角色路由 |
| `/teacher/courses/spring/studio` | 课程工作室 | 课程树、内容编辑、标签页、难度、预览、提交审核 |
| `/teacher/assignments` | 教学任务 | 状态筛选、展开、创建任务、关注事项 |
| `/teacher/reviews/submission-1` | 提交复核 | 学生切换、声证据播放器、评分、草稿、发布 |
| `/student/today` | 今日学习 | 桌面/移动响应、范读、缓存资源、网络状态 |
| `/student/learn/spring-2` | 学习播放器 | 真实录音、动态声波、暂停、完成、同步、继续 |
| `/student/growth` | 成长报告 | 证据播放、视角切换、路径节点、计划、导出 |
| `/assessment` | 测评入口 | 设备检查、继续未完成状态、历史记录 |
| `/assessment/reading/2` | 朗读测评 | 真实录音、声波、重录、同步、继续书面练习 |
| `/assessment/written` | 书面练习 | 6 题切换、答案选择、自动保存、提交报告 |
| `/assessment/report/demo` | 测评报告 | 后端数据水合、证据播放、建议、打印、复测 |
| `/assessment/history` | 历史复测 | 维度与范围切换、事件定位、安排复测、打印 |
