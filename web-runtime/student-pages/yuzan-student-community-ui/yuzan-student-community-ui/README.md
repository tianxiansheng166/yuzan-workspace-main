# 语赞心声｜学生语言实践社区高保真还原

这是独立静态网页包，不会写入现有项目。

## 运行

推荐使用本地 HTTP 服务，避免浏览器对本地文件的安全限制：

```bash
python -m http.server 4173
```

然后访问：`http://localhost:4173/`

也可以直接双击 `index.html` 打开。

## 实现边界

- 页面布局、导航、按钮、主题选择、播放控件、作品状态、弹窗和响应式布局均由 HTML/CSS/JavaScript 重建。
- 提供的插画仅作为独立的山脊、河谷、封面和纸张纹理素材使用，没有把整张参考页面作为网页背景。
- Logo 仅提取原图中的图形标志；中文名称和副标题由 HTML 渲染。
- 真实姓名、学校、作品状态、审核结果与权限目前为演示数据，接入生产环境时必须替换为真实接口和状态机。

## 响应式

- 桌面端：三栏完整构图。
- 平板端：右侧信息收起为抽屉。
- 手机端：主内容纵向排列，底部主导航，保留单一明确行动。
- 支持 `prefers-reduced-motion`。
