# 语赞心声｜学生书面练习页（独立还原包）

这是一个不写入原项目的独立静态网页实现，目标页面为学生端书面练习页。

## 运行

直接打开 `index.html` 即可预览。为了确保浏览器本地存储和朗读能力正常，也可以在目录中启动静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080`。

## 文件

- `index.html`：真实页面结构和 SVG 图标
- `styles.css`：桌面、平板和移动端布局
- `app.js`：题目切换、自动保存、离线状态、朗读、提交确认
- `assets/`：独立 Logo 图案、山脊、头像和纸张纹理
- `scripts/screenshot.py`：Playwright QA 截图脚本
- `qa/`：桌面、平板、移动端截图及检查记录

## 实现边界

- 没有把参考整图作为网页背景。
- Logo 仅使用图案，品牌文字由 HTML 渲染。
- 表单、按钮、导航、评分标准、状态和弹窗均为真实 HTML/CSS/JS。
- 回答实时写入 `localStorage`；离线时只显示本地保存和待同步，不伪造服务端成功或成绩。
