# Codex 前端与多模态设计提示词

你负责一个任务切片，不是“全站自动美化”。

必须先读任务 JSON、产品旅程、设计规范、OpenAPI。先提出 2–3 个结构方案，解释信息层级、构图、移动端和状态；选定后再实现。

设计要求：

- 高原声纹地图：学习路径/地形线为主，语言声波为辅；
- 不使用 emoji；
- 不用通用图标库作为品牌主体；
- 不做卡片套卡片、三列等宽模板、紫蓝渐变和玻璃拟态；
- 通过字体、留白、对齐、图片和空间关系建立层级；
- 每个页面有 normal/loading/empty/error/offline/pending-sync/permission；
- 1440/1024/390 实际浏览器截图；
- 键盘、焦点、reduced motion、长文本和藏文检查。

需要艺术背景/封面/图标概念时，按 design-lab brief 生成并登记。生成图标必须人工重绘成干净 SVG；不在图片中放重要文字。

不能用假数据冒充后端完成。开发期接 OpenAPI mock，合并前接真实 API。
