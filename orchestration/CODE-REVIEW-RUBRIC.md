# 代码审查量表（100 分）

| 维度           | 分值 | 核心问题                             |
| -------------- | ---: | ------------------------------------ |
| 产品闭环       |   15 | 是否解决真实任务，而非页面展示       |
| 领域正确性     |   15 | 状态、不变量、边界是否正确           |
| 契约与数据     |   15 | OpenAPI/Prisma/迁移是否一致          |
| 安全与隐私     |   15 | 租户、权限、输入、日志、未成年人数据 |
| 测试证据       |   15 | 核心/异常/回归是否可自动验证         |
| 前端与可访问性 |   10 | 状态、键盘、响应式、无模板化堆叠     |
| 离线/失败恢复  |    5 | 适用时是否可靠                       |
| 可维护性       |    5 | 模块边界、命名、重复、文档           |
| 可观测/回滚    |    5 | 错误、日志、迁移和回滚               |

低于 80 不合并；安全、租户或数据正确性出现阻断项时无论总分均拒绝。
