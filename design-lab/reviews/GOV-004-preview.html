基础 Token 与原语状态矩阵

本地预览只用于设计与无障碍验收，不接入生产路由。矩阵覆盖默认、悬停、焦点、按压、禁用、加载、错误与深色背景 variant。

当前预览复用了 tokens.css 与 base.css，但组件区块仍使用静态等价标记与同步样式，不是直接挂载真实 Vue SFC，因此可能与最终组件实现产生小幅漂移。

YxButton

Default / Hover / Active

Focus / Disabled / Loading

loading 使用明确文案，避免只用动画表示状态。

Contrast Surface

只提供 contrast variant，不扩展整站 dark mode。
