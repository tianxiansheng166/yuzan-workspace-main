# ACC-UI-001 visual concept

## Learning path / terrain

The product shell uses a warm paper field, forest contour lines and a single ochre route. The route connects the homepage hierarchy instead of splitting it into a wall of interchangeable cards.

## Language / waveform

Waveform geometry appears as a secondary rhythm inside the terrain and the closing dark-green band. It never carries status meaning by itself.

## Asset provenance

`ACC-UI-001-TERRAIN-001` was drawn as original SVG geometry by VM1-Codex-4 for this task. No external references, brands, portraits, student data or licensed materials were used. A raster generation attempt timed out and was not retained or used.
