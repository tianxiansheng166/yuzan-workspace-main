# 旧项目复用矩阵

旧项目的价值排序是：课程与内容 > 需求线索 > 页面原型 > 代码。任何资产进入新项目都要有来源、审核和转换记录。

| 旧资产 | 处理等级 | 新项目动作 | 责任人 | 风险 |
|---|---|---|---|---|
| 课程体系与教研文档 | A：优先复用 | 拆成课程/单元/课时/目标/活动，人工审校后版本化 | 教研+迁移 | 文档版本、重复、课程真实性 |
| `db/courses.json` | B：转换 | 导出为 staging seed，不直接运行 | 迁移 | 字段含义和套餐字段需重构 |
| 双语 JSON | B：待审语料 | 进入翻译表，保留译者/审校/版本 | 教研+i18n | 机器翻译、重复和字体 |
| 图片、封面、视频、字幕 | B/C | 核验版权、质量、校验和；无授权仅测试 | 内容运营 | 外链、版权、弱网体积 |
| 资源库标签/分类 | B | 复用概念，重建资源实体和审核流程 | 产品+教研 | 标签无口径 |
| 旧 API 端点 | C：需求参考 | 转成用例和 OpenAPI，代码重写 | 合同/API | 权限和数据模型错误 |
| 页面与截图 | C：流程/反例 | 提取 IA、文案和视觉问题，不复制 HTML | 设计 | 静态假数据、模板感 |
| 登录/JWT/bcrypt 代码 | C | 只参考意图，重新实现会话和租户权限 | 身份 | 默认密钥、范围越权 |
| `server.js` | D：淘汰 | 不迁入生产 | — | 单文件、静态根目录暴露 |
| `db/users.json` | D：拒绝 | 不迁移真实/疑似个人数据；仅生成虚构 seed | 隐私 | 未成年人信息 |
| `site-polish.js` | D：拒绝 | 不迁入 | — | DOM 猜测和运行时修补 |
| `yx-design-upgrade.css` | D：拒绝 | 仅提取经确认的颜色母题 | 设计 | 64+ `!important` 类覆盖 |
| 演示微服务 | D：归档 | 不继续修复 | — | 空壳和部署错误 |
| 购买/定价页面 | D：暂缓 | 商业验证后重做 | 产品 | 专家已质疑测算 |
| 社区/志愿者/公益模块 | D：暂缓 | 放入需求池 | 产品 | 偏离主闭环 |

## 强制规则

- 新应用不得运行时读取 `legacy/`。
- 旧数据迁移采用一次性脚本，不做长期双写。
- 导入失败要保留原因，不“尽量塞进去”。
- 每个媒体资产有版权状态：`approved / restricted / unknown / rejected`。
- 课程内容必须由领域老师确认，不由 AI 自动批准。
