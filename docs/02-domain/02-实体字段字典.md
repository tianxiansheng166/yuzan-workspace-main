# 核心实体字段字典

以下是 MVP 最小字段，不是完整数据库文档；最终以 Prisma schema 和迁移为准。

## School

- `id`
- `name`
- `code`
- `status`
- `timezone`
- `region_code`
- `created_at`

## User

- `id`
- `display_name`
- `login_identifier`
- `password_hash`
- `status`
- `preferred_locale`
- `created_at`

敏感信息不得为了“以后可能用”而收集。民族、住址、身份证、监护人信息不进入 MVP，除非有明确合法依据和业务必要性。

## Membership

- `user_id`
- `school_id`
- `role`
- `status`
- `joined_at`

唯一约束：`(user_id, school_id, role)`。

## Class / Enrollment

- `Class`: school, term, name, grade, lead_teacher
- `Enrollment`: class, user, type(student/teacher), status

## Course / CourseVersion

- `Course`: 稳定身份、标题、适用范围、所有者
- `CourseVersion`: version, status, objectives, locale/dialect metadata, published_at
- `Unit`, `Lesson`, `LearningActivity`: 有序结构
- `Resource`: 对象存储键、媒体类型、大小、校验和、版权和离线策略

## Assignment

- `school_id`
- `class_id`
- `course_version_id`
- `title`
- `starts_at`
- `due_at`
- `completion_rule`
- `offline_policy`
- `status`
- `revision`

## Submission

- `assignment_id`
- `student_id`
- `attempt_no`
- `status`
- `submitted_at`
- `server_revision`
- `device_id`
- `idempotency_key`

## SpeechResult

- `audio_asset_id`
- `target_text_version`
- `provider`
- `provider_model`
- `quality_flags`
- `recognized_text`
- `alignment`
- `score_components`
- `confidence`
- `processing_ms`
- `review_status`

## AuditLog

- `school_id`
- `actor_user_id`
- `action`
- `resource_type`
- `resource_id`
- `before_summary`
- `after_summary`
- `request_id`
- `created_at`

不得在审计日志中记录密码、完整 token、原始敏感音频或不必要的个人明细。
