# 关键状态机

## CourseVersion

```text
DRAFT → IN_REVIEW → APPROVED → PUBLISHED → RETIRED
          ↘ CHANGES_REQUESTED ↗
```

规则：

- `PUBLISHED` 不允许修改内容；
- `RETIRED` 不能创建新任务，但历史任务继续可读；
- 审核动作必须记录操作者和意见。

## Assignment

```text
DRAFT → SCHEDULED → OPEN → CLOSED → ARCHIVED
                    ↘ CANCELLED
```

规则：

- 发布后重要变更生成 revision；
- 已经同步到设备的 revision 必须能解释差异；
- `CANCELLED` 保留学生已产生的数据。

## Submission

```text
NOT_STARTED → IN_PROGRESS → PENDING_SYNC → SUBMITTED
                                      ↘ SYNC_CONFLICT
SUBMITTED → PROCESSING → NEEDS_REVIEW → REVIEWED → RETURNED
                                           ↘ ACCEPTED
```

规则：

- 本地“已完成”不等于服务端“已接收”；
- `RETURNED` 后建立新的 attempt；
- 任何人工修改保留原自动结果。

## SyncOperation

```text
QUEUED → SENDING → ACKNOWLEDGED
            ↘ RETRYABLE_ERROR
            ↘ CONFLICT
            ↘ PERMANENT_FAILURE
```

## SpeechJob

```text
CREATED → QUALITY_CHECKED → PROCESSING → AUTO_RESULT
              ↘ REJECTED_AUDIO           ↘ FAILED
AUTO_RESULT → NEEDS_REVIEW → FINALIZED
            ↘ FINALIZED（高置信度且策略允许）
```

学生界面不能把 `AUTO_RESULT` 误称为教师最终评价。
