# 试点上线运行手册

## 每日

- 检查 API/worker/数据库/对象存储健康；
- 检查同步积压和永久失败；
- 检查语音任务失败和成本；
- 检查备份结果；
- 处理支持工单；
- 不直接在生产数据库手工改数据，使用审计工具/修复脚本。

## 故障等级

- SEV1：数据泄露、跨租户访问、全体无法学习；
- SEV2：班级任务/同步大面积失败；
- SEV3：单功能失败、有绕行；
- SEV4：视觉或低影响问题。

SEV1 立即关闭相关功能、保全日志并通知负责人；不要为了比赛演示隐瞒。

## AI 降级

- 语音供应商不可用：录音继续保存，标记等待处理；教师可人工听取。
- 大模型不可用：课程和任务链不受影响。
- 低置信度：不向学生给确定性错误结论，进入教师复核。

## 数据修复

- 使用版本化脚本；
- 先在 staging 复现；
- 有 dry-run；
- 输出影响数量；
- 操作进入审计；
- 修复后有回归测试。
