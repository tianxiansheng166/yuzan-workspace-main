### 0.2 8 种页面状态

每个页面都必须实现以下 8 种状态，缺一不可。状态切换由数据驱动，不由路由驱动。

| 状态 | 触发条件 | 视觉特征 |
| --- | --- | --- |
| `loading` | 首次进入页面、数据未就绪 | 骨架屏（skeleton），禁止全屏 spinner |
| `normal` | 数据就绪且无异常 | 完整内容 |
| `empty` | 数据为空集合（如历史记录为空） | 插画 + 引导文案 + 主 CTA |
| `error` | 接口返回错误码（非 401/403） | 错误码对应的文案 + 重试按钮 |
| `offline` | `navigator.onLine === false` | 顶部黄条「当前离线，已保存到本地」+ 本地数据视图 |
| `permission` | 401 / 403 / `FORBIDDEN_TENANT` | 跳转登录或选校页，不展示错误页 |
| `processing` | Attempt 处于 `PROCESSING` 或 `NEEDS_REVIEW` | 进度条 + 预计完成时间 + 离开按钮 |
| `provider-unavailable` | `PROVIDER_NOT_CONFIGURED` / `PROCESSING_PENDING` | 顶部蓝条「评分服务暂未配置，录音已保存」+ 本地视图 |

### 0.3 三视口响应式

| 视口 | 宽度 | 用途 | 容器最大宽度 |
| --- | --- | --- | --- |
| 桌面 | 1440px | 教师办公场景 | 1200px 内容区，左右各 120px 留白 |
| 平板 | 1024px | 课堂平板 | 960px 内容区，左右各 32px 留白 |
| 手机 | 390px | 学生宿舍 / 移动场景 | 全宽，左右各 16px 留白 |

**学生端学习页面必须使用桌面/平板布局**（章程硬约束：Student-side learning pages must use non-mobile (desktop) layout; mobile pages should be removed）。仅「练习与测评中心」「历史记录」「正式报告」三个页面在 390px 视口下提供移动适配，其余执行类页面（P-PR-03 / P-EX-04 / P-SB-05 / P-PC-06）在 390px 下展示「请在电脑或平板上完成本次练习」提示页，不渲染录音 UI。

### 0.4 跳转守卫

- 任何进入 `P-EX-04` 的请求必须校验 `attempt.status ∈ {IN_PROGRESS, READY_TO_SUBMIT}`，否则跳转 `P-PC-06` 或 `P-RP-07`。
- 任何进入 `P-RP-07` 的请求必须校验 `attempt.status = COMPLETED`，否则跳转 `P-PC-06`。
- 任何进入 `P-PR-03` 的请求必须校验该学生存在 `practiceDeliveries` 中且 `visibleFrom ≤ now`，否则跳转 `P-PC-01` 并 toast「该练习尚未开放」。
- 离开 `P-EX-04` 时若 `attempt.status = IN_PROGRESS`，必须触发 `beforeunload` 二次确认。

## 4. P-EX-04 · 通用执行器

| 字段 | 值 |
| --- | --- |
| **Page ID** | `P-EX-04` |
| **页面名称** | 通用执行器 |
| **路由** | `/student/practices/run/{attemptId}（执行入口，解析当前 Item）`
                                        /student/practices/attempts/{attemptId}/items/{itemAttemptId}（具体 Item）` |
| **用户** | 学生 |
| **核心问题** | 当前这道题我要做什么？听 / 跟读 / 朗读 / 复述 / 答题？还剩几次重录？还有几题？ |
| **进入条件** | 从 `P-PR-03` 进入；或从 `P-PC-01`「继续上次」进入；`attempt.status ∈ {IN_PROGRESS, READY_TO_SUBMIT}` |
| **输入数据** | `FX.practiceVersion.sections`（5 sections，10 items 全量字段，含 targetText、示范音频、correctKeys 等）、`FX.attempt.itemAttempts`（10 条，按 itemRefId 匹配当前进度）、`FX.attempt.policySnapshot`（重录配额、答案揭示策略） |
| **主操作** | 按 Item 类型执行：① `LISTEN_ONLY` —— 播放示范音频 N 次，点击「下一题」；② `LISTEN_REPEAT` —— 听示范 → 准备倒计时 → 录音 → 可重录 → 「下一题」；③ `READ_ALOUD` —— 看文本 → 准备 → 录音 → 可重录 → 「下一题」；④ `LISTEN_RETELL` —— 听材料 N 次 → 准备 → 录音 → 可重录 → 「下一题」；⑤ `SINGLE_CHOICE / MULTIPLE_CHOICE` —— 选择 → 「下一题」；⑥ `SHORT_ANSWER` —— 输入文本 → 「下一题」 |
| **次要操作** | ① 顶部进度条（`已完成 X / 10`）；② Section 切换提示（Section 1 → 2 时全屏过渡动画 2 秒）；③ 「查看上一题」（只读，不可修改已提交的录音）；④ 「临时退出」（触发 `beforeunload` 二次确认，Attempt 保持 `IN_PROGRESS`） |
| **状态** | `normal`（答题中）；`processing`（录音上传中，按钮禁用）；`error`（`AUDIO_QUALITY_REJECTED` → 强制重录；`RECORDING_UPLOAD_FAILED` → 提供「重试上传」；`RE_RECORD_LIMIT_EXCEEDED` → 禁用重录按钮）；`offline`（录音保存到本地，顶部黄条提示，恢复网络后自动同步） |
| **前一页** | `P-PR-03`（首次）或 `P-PC-01`（继续） |
| **后一页** | 全部 10 题完成后 → `P-SB-05` |
| **权限** | `STUDENT` 且为该 Attempt 的 `studentUserId` |
| **API 需求** | `GET /api/v1/attempts/{attemptId}`（含 itemAttempts）、`POST /api/v1/attempts/{attemptId}/item-attempts/{itemAttemptId}/recordings`（init 上传）、`PUT /api/v1/recordings/{recordingId}/blob`（直传存储）、`PATCH /api/v1/item-attempts/{itemAttemptId}`（更新 status、writtenAnswer）、`POST /api/v1/speech-jobs`（触发评分） |
| **移动端变化** | 390px 下展示「请在电脑或平板上完成本次练习」提示页 |

**禁止出现的内容**：
- 在 `answerRevealPolicy=AFTER_SUBMIT` 模式下，禁止展示 `correctKeys / referenceAnswer / keyInformationPoints`。
- 禁止展示其他学生的录音或评分。
- 禁止「跳过本题」按钮（`allowSkip=false`）。
- 禁止在录音过程中切换题目（必须先完成或取消当前录音）。
- 禁止展示机器评分（评分在 `P-PC-06` 之后才出现）。

**关键跳转规则**：
1. `P-EX-04` 是唯一允许「继续上次」的页面，其他页面刷新后均回到 `P-PC-01` 或对应角色首页。
2. `P-PC-06` 是唯一允许后台运行的页面，学生离开后 Attempt 继续处理，完成后站内信通知。
3. `P-RP-07` 可被 `P-HS-09`、`P-PC-01`、`P-PC-06` 三处入口访问，需根据来源调整返回按钮目标。
4. `P-RC-08` 必须带 `attemptId` 参数，无参数时跳转 `P-HS-09` 让用户选择。
5. 任何「返回」操作若离开 `P-EX-04` 且 `attempt.status=IN_PROGRESS`，必须触发 `beforeunload` 二次确认。

## 11. 跨页面数据一致性约束

| 约束 | 校验位置 | 失败行为 |
| --- | --- | --- |
| 9 个页面引用的 `studentUserId` 必须一致 | 每个页面进入时校验 `FX.student.userId === GET /me.user.userId` | 跳转 `/login` |

| `practiceVersionId` 在 Attempt、Report、Review 中必须一致 | 后端在生成 Report / Review 时校验 | 返回 `CONTENT_HASH_MISMATCH` |
| `rubricVersionId` 在 Attempt、Report、Review 中必须一致 | 同上 | 返回 `RUBRIC_VERSION_MISMATCH` |
| 录音的 `itemAttemptId` 必须存在于 `attempt.itemAttempts` | 上传录音时后端校验 | 返回 `ITEM_ATTEMPT_NOT_FOUND` |
| Review 的 `itemAttemptId` 必须存在且 `status=NEEDS_REVIEW` | 教师提交复核时后端校验 | 返回 `REVIEW_CONFLICT` |
