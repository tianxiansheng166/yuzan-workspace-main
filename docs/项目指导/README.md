# 语赞心声项目指导

> 更新时间：2026-07-19  
> 当前目标：停止“继续铺页面”，把已有前端、API、worker 和数据模型收敛为一条可真实运行、可持续扩展的国通语学习闭环。

## 阅读顺序

1. `与ai对话确定方向.md`
   - 根据用户提供附件整理的方向讨论归档，完整原文仍以附件为准。
   - 它是产品意图来源，不直接作为开发任务单。
2. `00-全局诊断与下一步决策.md`
   - 对对话质量、当前代码事实和关键风险的总评。
   - 先看这一份，明确现在做什么、暂时不做什么。
3. `01-语赞心声产品总章程-v3.0.md`
   - 产品定位、用户价值、统一练习与测评内核、角色工作空间和成功标准。
4. `02-项目与前后端开发规范.md`
   - API、数据库、worker、前端、权限、异常状态、测试和交付规范。
5. `03-前后端一体化详细开发进程.md`
   - 以 20 个工作日为一个赶工周期的详细实施顺序、依赖和验收门槛。
6. `04-AI协作任务模板与验收清单.md`
   - 后续给 AI 下任务时直接复用的模板，防止再次出现“页面很多、闭环不通”。

## 本目录的裁决原则

发生冲突时，按以下顺序处理：

1. 用户当前明确决定；
2. 已经运行验证的代码事实；
3. `01-语赞心声产品总章程-v3.0.md`；
4. `02-项目与前后端开发规范.md`；
5. `03-前后端一体化详细开发进程.md`；
6. 旧状态文档和历史计划。

旧文档中的 `READY`、`PASS`、`PENDING` 只代表当时快照。当前状态必须用当前代码、接口响应和实际测试重新确认。

## 当前唯一 P0

第一条黄金闭环固定为“古诗文朗读与理解训练”：

```text
练习内容与评分标准
→ 学生查看详情并开始
→ 设备检查
→ 听辨/跟读/朗读/复述
→ 书面理解题
→ 上传录音与答案
→ 自动处理
→ 教师复核
→ 生成报告
→ 更新能力画像
→ 推荐巩固练习
```

这条链路没有以真实数据跑通前，不再把新增管理页、社区页、志愿者扩展页或更多静态视觉稿列为 P0。
