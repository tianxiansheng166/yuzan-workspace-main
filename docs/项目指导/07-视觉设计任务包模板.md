## 0. 视觉 AI 工作守则

### 0.1 你只做视觉，不碰业务

| 允许做 | 禁止做 |
| --- | --- |
| 配色、字体、间距、圆角、阴影、动效 | 修改任何业务字段名称、ID、数据值 |
| 布局结构（栅格、Flex、容器尺寸） | 增删页面或改变页面跳转关系 |
| 图标、插画、装饰元素的选择与绘制 | 修改状态机、错误码、API 路径 |
| 响应式断点下的视觉变化 | 修改 Rubric 权重、评分维度 |
| 空状态、加载状态、错误状态的视觉表达 | 修改 Section 顺序、题目数量 |
| 品牌元素（Logo、背景图、纹理）的应用方式 | 替换 FX 中的任何数据 |

### 0.2 你的输入

1. 本文档（07）
2. [design-fixtures/古诗文朗读与理解训练-v1.json](./design-fixtures/古诗文朗读与理解训练-v1.json)（FX）
3. [06-P0页面地图与状态流.md](./06-P0页面地图与状态流.md) §0 全局约定 + §1~§9 对应页面行

### 0.3 你的输出

每个页面交付 3 个视口的设计稿：
- 桌面 1440 × 900（主设计稿）
- 平板 1024 × 768
- 手机 390 × 844（仅 P-PC-01 / P-RP-07 / P-HS-09 / P-RC-08 / P-PC-06 五个页面需要）

输出格式：Figma / Sketch / PNG（1920px 宽导出）+ 一份 `design-notes.md` 说明配色、字体、间距 token。

### 1.5 语气与调性

> `FX.visualBrandReference.voiceAndTone`：克制、温润、清晰；以学生可见进步为语气主轴，不使用惊呼、绝对化承诺或营销腔。

视觉翻译：
- 不使用大红大绿的高饱和度对比。
- 不使用感叹号图标、爆炸效果、闪光效果。
- 进步用「上升折线 + 温润色」表达，不用「奖杯 + 金色」。
- 错误用「柔和红 + 引导文案」表达，不用「大红叉 + 警告色块」。

## 3. 页面前后关系

> 视觉 AI 必须为每个页面设计「返回」与「前进」的视觉线索，使页面跳转有连贯感。

```
P-PC-01 ──► P-PD-02 ──► P-PR-03 ──► P-EX-04 ──► P-SB-05 ──► P-PC-06 ──► P-RP-07
   ▲                                                                              │
   └────────────────────────「返回练习中心」──────────────────────────────────────┘
                                                                                  │
                                            P-RC-08 ◄──「听录音」──── P-RP-07 ──► P-HS-09
```

**视觉连贯性要求**：
1. 每个页面顶部必须有「面包屑」或「返回按钮」，标明当前所在环节（如「练习详情 / 古诗文朗读与理解训练 / 准备开始」）。
2. 执行器（P-EX-04）顶部进度条必须用 `routeStrip` 背景图，标注当前 Section（1/5、2/5 …）。
3. Section 切换时全屏过渡动画 2 秒（淡入淡出 + Section 标题居中展示）。
4. 从 P-RP-07 跳转到 P-RC-08 时，录音列表必须高亮来源录音（`accentSunrise` 边框 2px）。

## 5. 必须设计的状态（按页面）

> 每个页面必须为以下状态提供视觉稿。状态定义见 [06-P0页面地图与状态流.md](./06-P0页面地图与状态流.md) §0.2。

| 页面 | 必须设计的状态 |
| --- | --- |
| P-PC-01 | `loading`（骨架屏 3 卡片）、`normal`（2 张投递卡片 + 历史摘要）、`empty`（插画「老师还没布置练习」）、`error`（错误码文案 + 重试）、`offline`（顶部黄条 + 本地卡片） |
| P-PD-02 | `loading`、`normal`、`error`（练习不存在）、`permission`（无权访问） |
| P-PR-03 | `loading`（创建 Attempt 中）、`normal`（4 项检查卡片，含 PASS/FAIL/未检查三态）、`error`（某项 FAIL） |
| P-EX-04 | `normal`（答题中）、`processing`（录音上传中，按钮禁用 + 进度环）、`error`（`AUDIO_QUALITY_REJECTED` 红色提示 + 强制重录）、`offline`（顶部黄条 + 本地保存提示） |
| P-SB-05 | `normal`（全部完成，提交按钮可用）、`error`（红色标注未完成项）、`processing`（提交中）、`offline`（本地有未同步录音） |
| P-PC-06 | `processing`（进度环 + 「已评分 X/10」）、`provider-unavailable`（蓝条提示）、`error`（SCORING_ERROR 红色页） |
| P-RP-07 | `loading`、`normal`、`processing`（跳转 P-PC-06）、`error`（报告生成失败） |
| P-RC-08 | `loading`、`normal`、`empty`（无录音插画）、`error`（录音损坏） |
| P-HS-09 | `loading`、`normal`、`empty`（插画「还没有练习记录」）、`error` |

**状态视觉规范**：
- `loading`：使用骨架屏（`paperWarm` 色块 + 微光动画 1.2s 循环），禁止全屏 spinner。
- `empty`：插画尺寸 240×180，居中，下方引导文案 `body-lg`、`inkMuted`，再下方主 CTA 按钮。
- `error`：错误图标 48×48 `danger` 色，错误码文案 `body-md`，下方「重试」按钮 `accentSunrise`。
- `offline`：顶部黄条 36px 高 `#F5E6B8` 背景，`inkBody` 文字「当前离线，数据已保存到本地」。
- `processing`：圆形进度环 80×80 `accentSunrise`，配 `body-lg` 文案。
- `provider-unavailable`：顶部蓝条 36px 高 `highlandSlate` 背景，`paperBase` 文字。
- `permission`：不设计独立页面，直接跳转登录或选校页。
