# 06 视觉设计审查清单

## 产品

- [ ] 服务国通语“学习—练习—证据—报告—干预”闭环。
- [ ] 同时解释自主练习与教师布置，但只展示 P0 支持的模式。
- [ ] 课程、练习、证据、报告与下一步关系清楚。
- [ ] 全部故事数据来自统一 Fixture。

## 流程

- [ ] S01—S09 前后连续，没有死路。
- [ ] 每个按钮都有成功、失败和权限结果。
- [ ] 未完成 Attempt 能恢复到最近未完成 Item。
- [ ] 设备失败、离线、本地保存、同步、提交、处理没有混为一谈。
- [ ] PROPOSED/BLOCKED 不被画成已经接通。

## 层级

- [ ] 每页只有一个主任务和一个视觉焦点。
- [ ] 次要说明明显弱化，技术检查默认折叠。
- [ ] 没有卡片墙、卡中卡或所有模块同权。
- [ ] 技术 ID 不出现在学生界面主体。

## 功能与状态

- [ ] normal/loading/empty/error/offline/permission 适用状态齐全。
- [ ] processing/provider-unavailable 适用状态齐全。
- [ ] S04 执行状态齐全，且没有 `setTimeout` 假完成。
- [ ] 本地保存与服务端同步分别表达。
- [ ] 接口失败不会继续显示 Fixture 成功分数。

## 响应式与无障碍

- [ ] 1440 充分使用空间，主次比例明确。
- [ ] 1024 发生重排，不是整体缩放。
- [ ] 390 按阅读顺序重构，触控区至少 44×44。
- [ ] 键盘、焦点、live region、对比度、reduced motion 合格。
- [ ] 执行类页面在 390 明确正式设备限制。

## 品牌

- [ ] 保持暖白、朱红/日出、灰绿、浅金/纸暖与深青灰。
- [ ] 高原、路径、声波按页面职责分配。
- [ ] 不用紫蓝渐变、玻璃拟态、emoji、奖杯、金牌或星星。
- [ ] 不做统一悬浮上移效果，不复制同一构图到九页。
- [ ] 新资产在进入正式实现前完成资产登记。
