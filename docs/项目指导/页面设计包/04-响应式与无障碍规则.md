# 04 响应式与无障碍规则

## 断点与重排

| 视口 | 内容区 | 重排规则 |
| --- | --- | --- |
| 1440 | 最大 1200px | 12 列；主任务占 7—8 列，次要摘要占 4—5 列 |
| 1024 | 左右各 32px | 8 列；并列区按阅读顺序转上下 |
| 390 | 左右各 16px | 4 列；底部固定操作预留安全区，不做固定画布缩放 |

390 验收截图用于验证信息结构。S03/S04/S05 的正式执行仍提示使用电脑或平板；S06 可以移动查看处理状态。

## 可访问性

- 文字与背景对比至少 4.5:1；大字至少 3:1。
- 可点击区域移动端至少 44×44，桌面按钮至少 36 高。
- 颜色不是唯一状态信号；同时使用文案、形状和 `aria-label`。
- 进度用 `<progress>` 或带 `aria-valuenow` 的语义元素。
- 音频控制提供播放状态、剩余次数和文本说明；不自动播放。
- 录音倒计时、开始、停止、保存、上传结果均由 live region 宣告。
- 波形为装饰时 `aria-hidden=true`；证据含义用文字提供。
- 表格在 390 转为带字段名的定义列表，不隐藏关键列。
- 输入错误与字段建立 `aria-describedby` 关联。
- 焦点可见轮廓不小于 2px；键盘可完成所有非录音硬件动作。
- `prefers-reduced-motion: reduce` 时取消非必要动效。

| 页面 | 1440 | 1024 | 390 |
| --- | --- | --- | --- |
| S01 | 入口主区 + 截止/继续摘要 | 两区上下 | 单列任务流 |
| S02 | 目标正文 + 练习结构 | 概要下移 | 单列、开始按钮吸底 |
| S03 | 四项设备检查 + 说明 | 2×2 | 设备提示 + 检查结果摘要 |
| S04 | 专注任务区 + 题侧栏 | 侧栏下移 | 设备提示 + 结构预览 |
| S05 | 证据清单 + 提交门槛 | 摘要下移 | 设备提示 + 阻塞摘要 |
| S06 | 中央处理路径 | 同结构 | 单列完整适配 |
| S07 | 报告证据 + 下一步 | 纵向分区 | 总结优先，图表可横滚 |
| S08 | 录音档案 + 播放详情 | 上下结构 | 列表优先 |
| S09 | 时间轴 + 趋势 | 上下结构 | 纵向时间轴 |
