# 第二批页面视觉提示词

在同一页面族母版下，为 S06—S09 生成高保真设计。每页提供 1440 与 390；S07 额外提供 1024。继续使用卓玛措、李雪梅、七年级A班和同一 Fixture。

## S06 评分处理中

唯一目标：解释系统在做什么、学生是否需要等待。焦点是一条从“证据已接收”到“机器分析/教师复核/报告可读”的路径节点。必须有：先去别处看看、刷新状态、完成通知开关、处理详情、不可恢复错误时联系教师。

状态稿：processing、provider unavailable、error、offline。provider unavailable 必须明确“录音已保存，评分服务暂不可用”，绝不显示 Fixture 的 76.7；不使用倒计时秒数，不用定时器假完成，不提供取消提交。

## S07 正式报告

唯一目标：用证据解释本次表现并给出一项下一步。准确使用总分 76.7、通过线 60、人工关注线 75、5 Section、8 维结果、2 项优势、2 项改进、李雪梅教师反馈和“停顿与节奏专项训练”。焦点是证据如何指向下一步，不是八个同权分数卡。

必须有：开始巩固练习、加入学习计划、听录音、展开 Section、展开教师复核、查看历史、申请复测、返回中心。申请复测只能产生等待教师审批，不能直接创建复测。状态稿：normal、loading、data insufficient、error、offline。data insufficient 不能显示 76.7 或强结论。图表必须有可读表格替代。

## S08 我的录音

唯一目标：找到本人录音并理解保存/上传/处理状态。焦点是一条选中的声音证据。使用 5 段 Fixture 录音标题，设计成克制的声音档案，不做娱乐网站播放器。

必须有：播放/暂停、上一段、下一段、选择录音、返回报告、查看历史、状态说明。下载接口未冻结时只能显示不可用说明，不生成假文件。状态稿：normal、loading、empty、error、offline、processing/provider unavailable。禁止重录、其他学生录音、技术 objectKey。

## S09 历史记录

唯一目标：理解过去做过什么和发生了什么变化。准确使用三次记录：64.0、71.4、76.7；三条趋势：发音 68→74→79、停顿 60→68→73.75、信息点 55→60→65。焦点是一条三次练习的时间路径。

必须有：查看报告、时间范围筛选、作业/自主筛选、三维趋势切换、清除筛选、返回中心、了解复测。状态稿：normal、loading、empty、error、offline、processing。不要把三个点夸张成长期因果，不展示排名、奖杯或其他学生。

## 批次输出要求

每页附：唯一焦点、证据来源、主次按钮、母题分配、状态差异、响应式重排。四页不得同时使用大雪山、太阳、飞鸟、完整路径、等高线、大声波和装饰印章。接口缺口放设计注释；学生画面只显示真实可理解状态。
