# 第一批页面视觉提示词

在已确认“页面族统一视觉母版”后，为 S01—S05 生成高保真设计。每页先给 1440，再给 390；S01、S04 额外给 1024。正式一级导航只能是“今日学习 / 课程学习 / 练习与测评 / 成长档案”，全页激活“练习与测评”；“首页 / 练习 / 历史 / 我的”只作页面内快捷入口。使用同一卓玛措故事和同一 Fixture，不新增/删除业务按钮。

## S01 练习与测评中心

唯一目标：判断现在做什么。焦点是一条高原学习路径指向“古诗文朗读与理解训练”，而不是任务卡片墙。突出当前作业、继续上次、自主练习的优先级；最近完成只作弱摘要。必须有：开始作业、继续上次、自主练习、查看详情、查看历史、刷新。不要展示技术 ID、其他学生、排名或大量统计。

状态稿：normal、loading、empty、error、offline。empty 不创造练习；offline 只显示已确认缓存。母题只在本页使用完整高原学习路径。

## S02 练习详情

唯一目标：理解训练什么、怎么完成、结果如何使用。采用编辑式长文导读与章节索引，不使用大 Hero 或卡片堆叠。准确呈现：约 22 分钟，示范听辨、听后跟读、看文朗读、听后复述、书面理解五环节，以及设备、证据、教师复核和结果用途。必须有：开始练习、返回、三个折叠说明。

禁止展示题干、答案、技术 ID、跳过、教师编辑按钮。390 的开始按钮可吸底但不能遮内容。

开始流程必须表现为：点击开始 → 创建或恢复 Attempt → 后端返回 `attemptId` → 进入 S03 `/student/practices/attempts/:attemptId/prepare`，不得直接用 PracticeDefinition 路由进入设备检查。

## S03 准备与设备检查

唯一目标：判断设备是否能开始。焦点是浏览器—麦克风—扬声器—网络构成的声音回路。准确区分：浏览器/麦克风/扬声器失败会阻塞；网络失败进入 LOCAL_ONLY，可以继续练习但提交前必须同步。必须有：开始设备检查、单项重新检查、播放测试音、进入练习、返回详情。

状态稿：normal、检查中、设备阻塞、offline/LOCAL_ONLY。错误要附具体修复步骤，不使用笼统大红叉。390 至少画 SELF_PRACTICE 可执行状态，保留完整四项检查、听音与进入动作；STAGE_ASSESSMENT 只显示测评信息和“本次阶段测评需要使用电脑或平板”，不进入设备录音流程。COURSE_PRACTICE 默认允许但可被 DeliveryPolicy 限制，ASSIGNMENT 服从教师发布策略并显示具体阻塞原因与建议设备。

## S04 通用执行器

先设计一个不会随题型跳位的统一外壳：练习名称、Section、Section/题目进度、保存同步、网络、退出、当前任务说明、中央任务区、上一题/下一题、帮助、折叠技术详情。唯一焦点永远是中央任务区。

中央任务区的单页高保真目标只使用 Fixture 已有实例：LISTEN_ONLY、LISTEN_REPEAT、READ_ALOUD、LISTEN_RETELL、SINGLE_CHOICE、SHORT_ANSWER，Fixture 另有 MULTIPLE_CHOICE 可作为补充变体。LISTEN_ANSWER 与 FILL_BLANK 保持 `NO_FIXTURE_INSTANCE`，只在统一外壳设计板中画空结构和组件规则，清楚标“当前设计 Fixture 无实例”；不得编造题目、答案、时长、分数，也不得把它们作为第一批单页高保真生成目标。

必须体现 playing、preparing、recording、reviewing、saved local、uploading、upload failed、synced、audio rejected、completed；录音中不能切题；音质拒绝不消耗重录次数；本地保存不能写成已同步；任何状态都不显示分数。390 至少画 SELF_PRACTICE READ_ALOUD 可执行状态，提供重新设计的移动录音控件、听音、本地保存与题目导航；不得缩放桌面圆形录音控件。另画 STAGE_ASSESSMENT 阻塞状态，不渲染正式作答和录音流程。

## S05 提交前检查

唯一目标：确认所有必要内容完成且安全同步。焦点是 10 项完成证据汇入一个提交门槛；5 段录音和 3 道书面题的状态必须可核对。必须有：确认提交、返回修改、查看问题项、重试全部/单条上传、提交说明。

状态稿：可提交、未完成、upload failed、offline、提交中。未同步、上传失败、Fixture 缺 Item 都必须禁用提交并解释原因；不能提供“跳过直接提交”。390 至少画 SELF_PRACTICE 可执行提交检查，完整保留证据核对、返回修改和确认提交；COURSE_PRACTICE/ASSIGNMENT 按 DeliveryPolicy 处理，阻塞时显示具体原因与建议设备。STAGE_ASSESSMENT 手机不会从 S04 正式到达 S05。

## 批次输出要求

每页输出时附一张短表：唯一焦点、主操作、次要操作、使用母题、未使用母题、normal/异常状态差异、1440→1024→390 重排。所有技术接口状态只出现在设计注释，不进入学生画面。
