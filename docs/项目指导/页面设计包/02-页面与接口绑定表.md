# 02 页面与接口绑定表

## 判定口径

- `CURRENT`：当前 OpenAPI 与后端存在，且能完成同一原子动作。
- `PARTIAL`：有可组合能力，但路径、聚合、权限、状态或 Practice 语义不完整。
- `PROPOSED`：当前 OpenAPI 与后端均不存在。
- `BLOCKED`：局部能力存在，但安全、事务或评分正确性使其不能正式使用。

表内路径省略部署前缀 `/api/v1`。`视觉阻塞=否` 只表示可依 Fixture 完成设计，不表示可上线。

## 统计说明

本表按 31 个“用户原子动作”统计：`CURRENT 9 / PARTIAL 17 / PROPOSED 1 / BLOCKED 4`。这一口径不得与上游集成报告的 26 行按行统计直接比较，也不得据此声称后端接口完成度提高。S08 的读取、短时播放和 LOCAL_ONLY 管理规则是现有原子动作行内的权限约束，不新增或重分类接口状态。

### S08 录音权限冻结

- 学生只能读取自己的录音，并只能取得短时 playback URL。
- LOCAL_ONLY 且未上传的本人录音可以删除。
- 已同步并成为测评证据的录音不可直接删除。
- 不提供公开分享，不展示永久对象存储 URL。
- 教师录音访问保持 `BLOCKED`，直到任课班级校验完成。

## 对象覆盖结论

| PracticeDefinition | PROPOSED | 设计可继续，正式实现需新领域契约 |

| History | PARTIAL | 旧事件可读，Practice 投影和 8 维趋势不完整 |
| LearningPlan / Consolidation suggestion | PARTIAL | backend-only，不得作为 CURRENT 前端契约 |
