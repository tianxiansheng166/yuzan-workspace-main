# 03 统一状态与错误文案

## 页面状态

| 状态 | 触发 | 学生可见文案 | 可用动作 |
| --- | --- | --- | --- |
| loading | 首次数据未就绪 | 正在准备页面内容 | 允许返回 |
| normal | 数据完整 | 进入主任务 | 页面主操作 |
| empty | 合法空集合 | 当前还没有可显示的内容 | 返回/发现内容 |
| error | 非权限业务错误 | 暂时无法完成这一步 | 重试/返回 |
| offline | `navigator.onLine=false` | 当前离线；仅标明实际已保存在本机的内容 | 继续本地允许动作 |
| permission | 401/403/越权 | 你无权查看此内容 | 登录/返回 |
| processing | 后台评分或复核 | 证据已提交，系统正在处理 | 离开、稍后查看 |
| provider-unavailable | 供应商未配置/不可用 | 录音已保存，评分服务暂不可用 | 离开、稍后查看 |

## 执行器状态

| 状态 | 事实 | 禁止误导 |
| --- | --- | --- |
| playing | 用户触发音频播放 | 不自动播放 |
| preparing | 准备倒计时 | 不表示已经录音 |
| recording | 本地正在录制 | 不允许切题 |
| reviewing | 本地回听或核对 | 不表示已上传 |
| saved-local | IndexedDB 已保存 | 不写“已同步” |
| uploading | 正在上传 | 禁止离开且声称已完成 |
| upload-failed | 上传失败、本地副本仍在 | 不删除本地证据 |
| synced | 服务端确认录音/答案 | 可进入提交检查 |
| audio-rejected | 服务端拒绝音质 | 强制重录且不消耗配额 |
| completed | 当前 Item 已满足完成条件 | 不等于 Attempt 已评分 |

## 稳定错误码文案

| 错误码 | 文案 | 动作 |
| --- | --- | --- |
| VALIDATION_FAILED | 提交内容不完整，请检查后再试。 | 返回检查 |
| FORBIDDEN_RESOURCE | 你无权查看或操作此内容。 | 返回练习中心 |
| CONFLICT | 页面状态已变化，请刷新后继续。 | 刷新 |
| IDEMPOTENCY_CONFLICT | 这次上传与已有记录冲突，请保留本机内容并重试。 | 保留并重试 |
| PROCESSING_PENDING | 证据仍在处理中，请稍后查看。 | 离开/刷新 |
| ASSESSMENT_NOT_FOUND | 没有找到这次练习记录。 | 返回中心 |
| ASSESSMENT_ITEM_NOT_FOUND | 没有找到当前题目。 | 刷新练习 |
| RECORDING_NOT_FOUND | 没有找到这段录音，或你无权访问。 | 返回录音列表 |
| SPEECH_JOB_NOT_FOUND | 没有找到评分任务。 | 返回处理中 |
| PRACTICE_CONTENT_EMPTY | 这项练习暂时没有可用内容。 | 返回中心 |
| ASSESSMENT_HAS_NO_ITEMS | 这项练习还没有题目，暂时不能开始。 | 返回详情 |
| AUDIO_QUALITY_REJECTED | 这段录音不够清晰，请调整环境后重录；本次不占重录次数。 | 重新录音 |
| PROVIDER_NOT_CONFIGURED | 录音已保存；评分服务尚未配置。 | 离开/稍后查看 |
| PROVIDER_UNAVAILABLE | 录音已保存；评分服务暂时不可用。 | 稍后重试 |
| fixture-load-failed | 设计Fixture加载失败 | 重新加载 |

## 离线规则

网络检查失败进入 `LOCAL_ONLY`，不阻止练习；麦克风、扬声器、浏览器录音能力失败才阻止。S05 在任何必要录音尚未服务端确认时禁用“确认提交”。禁止通过 `setTimeout` 模拟上传、评分或报告完成。
