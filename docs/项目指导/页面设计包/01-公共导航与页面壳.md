# 01 公共导航与页面壳

## 学生导航

一级入口固定为：`今日学习 / 课程学习 / 练习与测评 / 成长档案`。本页面族激活“练习与测评”；S08/S09 仍属于该页面族，不另造一级入口。

“首页 / 练习 / 历史 / 我的”只能出现在页面内容区的快捷入口或返回文案中，不能出现在桌面或移动正式一级导航中。

桌面壳从左到右：

1. 品牌标记与“语赞心声”；
2. 四个一级入口；
3. 网络与同步摘要；
4. 卓玛措、七年级A班的账户入口。

移动壳：

- 顶部保留品牌、页面标题与账户；
- 一级入口收为底部导航；
- 底部导航仍使用四个冻结的完整名称，不以“首页/练习/历史/我的”替换；
- 页面内步骤导航改为横向可滚动的短标签，不整体缩放。

## 统一页头

- 面包屑：`练习与测评 / 古诗文朗读与理解训练 / 当前页面`。
- 页面标题只出现一次。
- 状态条只呈现对当前决策有用的信息：离线、未同步、处理中、服务不可用。
- 不展示 schoolId、attemptId、recordingId 等技术 ID。

## 执行壳

S03—S06 共用连续任务壳：

- 当前练习名称；
- 5 个 Section 的整体进度；
- 当前题进度；
- 保存/同步状态与网络状态；
- “临时退出”；
- 主任务区；
- 上一题/下一题；
- 帮助；
- 可折叠设计检查面板。

S04 只有中央任务区随题型变化。录音、播放、选择、填空、文本作答均不得改变导航、进度、保存与退出的位置。

S03 不是按 PracticeDefinition 直接进入：S02 的开始操作先创建或恢复 Attempt，拿到 `attemptId` 后进入 `/student/practices/attempts/:attemptId/prepare`，检查完成再进入 S04 当前 Item。

## 焦点与键盘

- 跳过导航链接为首个可聚焦元素。
- 焦点顺序遵循视觉顺序；不使用正数 `tabindex`。
- 所有状态变化通过 `aria-live="polite"` 宣告；阻塞错误用 `role="alert"`。
- 对话框触发后锁定焦点，关闭后返回触发按钮。
- `Escape` 只关闭次要面板，不中止录音或提交。
- 支持 `prefers-reduced-motion`；线框默认无大幅动画。

## 设计检查面板

折叠面板必须显示：

- 页面 ID 与目标路由；
- 当前 Fixture 引用；
- 当前动作的 API 状态；
- 正式实现阻塞项；
- 前后页面。

该面板是设计/工程审查工具，不属于正式学生界面。
