# 研究参考与核验规则

此目录用于记录竞品、框架、模型、法规和论文。任何外部能力在进入 ADR 前必须重新核验官方网站、许可证、版本、成本和可用区域。

优先研究：

- Kolibri：离线内容、课程/测验和同步；
- Canvas/Moodle：课程、任务、提交、评分和权限领域模型；
- Khan Academy：学生下一步和掌握度呈现；
- 国家智慧教育平台：资源治理和课程组织；
- 希沃/ClassIn：教师工作流；
- 藏语/民族语言 AI 供应商和开源模型：必须通过同一测试集评测。

注意：

- 研究文档中的准确率、延迟、用户数和价格不能直接当成项目数据；
- 不复制竞品 UI、资产、商标或专有内容；
- 技术选型以当前官方文档和 PoC 结果为准。
