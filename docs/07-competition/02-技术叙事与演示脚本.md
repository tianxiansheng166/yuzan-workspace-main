# 比赛技术叙事与演示脚本

## 30 秒

“语赞心声不是把支教活动搬到网页上，而是把课程、任务、离线学习、语音反馈和教师干预固化为可复制的数字教学闭环。学生断网仍能学，联网后可靠同步；自动语音结果保留置信度并由教师复核。”

## 3 分钟演示

1. 教研工作台：展示课程版本和审核，不停留在首页宣传。
2. 教师：选已发布课时，给试点班级布置任务。
3. 学生：进入今日任务，切换为离线模式完成图文/练习/录音。
4. 恢复网络：展示 outbox、幂等回执和同步状态。
5. 教师：查看原始录音、自动建议、置信度，修正并反馈。
6. 报告：展示真实任务完成和同步指标，说明口径。
7. 技术证据：一页基准结果与局限，不夸大。

## 评委追问准备

- 为什么不直接用国家平台？
- 没网如何登录和保护数据？
- 语音评分如何证明可靠？
- 方言差异如何处理？
- 换一批志愿者是否还能运行？
- 学校为什么付费，验收是什么？
- 如何保护未成年人音频？
- 为什么不是微服务？
- 目前哪些已经实现，哪些仍是规划？

回答必须区分“已实现、已测试、试点中、规划中”。
