# 专家意见到产品证据映射

## 新文科数字化

专家要求不是增加 AI 按钮，而是把人力帮扶转成可复用系统。

证据：

- 标准化课程版本；
- 教师任务和学生提交的真实数据链；
- 自动处理与人工复核；
- 连续试点日志；
- 内容和运营标准。

## 边缘计算、低延迟语音、无网适配

证据：

- 端/校内节点/云三级架构；
- 飞行模式 E2E；
- 同步幂等和冲突报告；
- 模型/供应商设备基准；
- P50/P95、内存、体积、准确性与分组差异；
- AI 失败时的降级链路。

## 去人力依赖与可复制

证据：

- 新学校初始化清单；
- 课程包、教师手册和管理员手册；
- 标准账号/班级导入；
- 运维、备份和支持 SOP；
- 新团队在不依赖原支教成员时完成演示/试点。

## 学生成长与教学 BI

证据：

- 指标口径；
- 事件和 SQL 来源；
- 教师因报告采取的行动；
- 不以静态 Chart.js 截图代替。

## 四个存续问题

1. 去掉志愿者：核心价值是软件、课程、离线内容包、语音反馈和教师工作流。
2. 脱离支教团：由学校成员通过标准操作使用，平台团队提供产品和内容服务。
3. 无政府资源：产品仍能为学校/机构提供可验收的教学效率和学习数据价值。
4. 老师不配合：不能假设完全不需要教师；应降低教师负担、提供自主学习价值，同时明确教育产品仍需合理教学治理。

最后一点必须诚实：未成年人教育产品不应以“完全绕过学校和教师”为卖点。
