# 测试策略

## 测试金字塔

### 单元测试

适合：

- 状态机；
- 截止时间/完成规则；
- 权限策略；
- 同步合并；
- 评分计算；
- 指标口径。

### 集成测试

使用真实 PostgreSQL 容器验证：

- Prisma 约束；
- 事务；
- 多租户查询；
- 幂等；
- outbox；
- migration。

### 契约测试

- OpenAPI lint；
- 生成类型能编译；
- mock 与 API 响应一致；
- breaking change 检查；
- 错误 code 覆盖。

### E2E

Playwright 核心场景：

1. 教研发布；
2. 教师布置；
3. 学生完成/提交；
4. 教师反馈；
5. 学生收到反馈；
6. 离线完成与恢复；
7. 跨租户越权失败。

### 视觉回归

只对稳定关键页面和组件建立基线；动态内容使用固定 seed。视觉差异必须人工确认，不能盲目更新快照。

### 安全和性能

- IDOR、上传、认证、速率、CORS、secret；
- k6/等价工具测关键 API；
- 弱网模拟和大内容包；
- 性能门槛基于试点设备，而不是高端开发机。

## 测试数据

- 全部虚构；
- 明确标记学生/教师角色；
- 多学校、多班级、多状态；
- 覆盖藏文、长标题、空值和特殊字符；
- 不复制旧 `users.json` 的个人信息。
