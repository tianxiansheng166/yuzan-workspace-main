# Definition of Done

任务只有同时满足以下条件才可标记 DONE。

## 产品

- 用户故事有明确主体、前置条件和结果；
- 不引入未批准范围；
- loading/empty/error/offline/permission 状态有定义；
- 文案不是开发占位符。

## 数据与契约

- 数据模型表达业务不变量；
- API 与 OpenAPI 一致；
- 前端不使用未声明字段；
- 破坏性契约变化有迁移和兼容计划；
- 敏感字段经过最小化审查。

## 安全

- 认证主体来自服务端上下文；
- 资源范围/租户权限已验证；
- 有负向越权测试；
- 输入验证、速率和文件规则适用；
- 日志无敏感内容。

## 工程

- lint、typecheck、unit、integration/build 通过；
- 没有新建“临时全局补丁”；
- 没有复制粘贴大型组件；
- 数据库迁移可在空库和已有库执行；
- 失败可回滚或安全前滚。

## 前端

- 使用真实 API 或契约 mock；
- 1440/1024/390 视觉检查；
- 键盘可操作、焦点可见；
- reduced motion；
- 无控制台错误、未处理 Promise 和资源 404；
- 不出现无意义卡片、emoji 或模板化图标堆叠。

## 测试证据

- 单元测试覆盖核心规则；
- API 集成或契约测试；
- 关键链路 E2E；
- bug 修复包含回归测试；
- PR 附截图、测试命令和结果摘要。

## 文档与交接

- 更新相关 ADR/契约/运行说明；
- 说明环境变量和迁移；
- 交接模板完整；
- 未完成风险和后续任务已登记。
