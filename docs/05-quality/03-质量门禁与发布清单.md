# 质量门禁与发布清单

## PR 门禁

- [ ] 任务 ID 与 allowed paths 匹配
- [ ] 无未批准共享契约变化
- [ ] lint/typecheck/test/build
- [ ] 数据库 migration 检查
- [ ] 权限负向测试
- [ ] OpenAPI 校验
- [ ] 无 secret
- [ ] 截图和状态矩阵
- [ ] 交接说明

## Staging 门禁

- [ ] 从空库部署成功
- [ ] 从上一版本升级成功
- [ ] seed 数据和演示账号
- [ ] E2E 全链路
- [ ] 对象存储签名 URL
- [ ] worker 重试与死信
- [ ] 离线 smoke test
- [ ] 日志和指标可见
- [ ] 数据导出审计
- [ ] 备份成功

## 试点发布门禁

- [ ] 隐私/授权材料
- [ ] 学校管理员培训
- [ ] 教师操作手册
- [ ] 设备和网络基线
- [ ] 支持与事件响应
- [ ] 备份恢复演练
- [ ] 语音功能免责声明与人工复核
- [ ] 回滚方案
- [ ] 试点指标和结束条件

## 比赛演示门禁

- [ ] 演示路径离线可运行或有可靠备用
- [ ] 数据来源真实、可解释
- [ ] 任何技术数字有测试报告
- [ ] 不展示真实未成年人敏感信息
- [ ] AI 失败时核心教学链仍可完成
