# 性能与资源预算

初始预算需要在试点设备上校准。

## Web

- 首屏 JS 避免大而全；按角色/功能切分；
- 关键页面在弱网下优先展示任务骨架和本地数据；
- 首屏装饰图片不阻塞核心操作；
- 单个艺术封面提供响应式尺寸和现代格式；
- 字体子集化，避免为展示字体加载大量字符；
- 列表分页/虚拟化只在真实数据量需要时使用。

## API

- 常用列表有明确索引；
- 避免 N+1；
- 报表与业务事务隔离；
- 文件直传对象存储，API 不长期转发大文件；
- P95 目标按本地/试点网络分别记录。

## 离线包

- 显示包大小和剩余空间；
- 资源按课时/任务细粒度选择；
- 支持校验和和断点续传；
- 视频多码率策略基于真实内容和设备测试；
- 自动清理必须可解释且不删除未同步数据。

## 语音

记录：

- 录音时长上限；
- 压缩格式；
- 上传体积；
- 设备质检时间；
- 服务处理 P50/P95；
- 模型内存和冷启动；
- 成本/分钟。
