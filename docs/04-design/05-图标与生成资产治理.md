# 图标与 AI 生成资产治理

## 图标系统

核心产品符号建议控制在 12–20 个：

- 今日路径；
- 课程/课时；
- 录音/播放；
- 下载/离线；
- 同步/冲突；
- 提交；
- 教师反馈；
- 审核/版本；
- 班级；
- 报告。

统一：

- 24×24 viewBox；
- 光学尺寸；
- 描边/填充逻辑；
- 端点和转角；
- 不同背景下的反色；
- hover/focus/disabled；
- 可访问名称。

简单系统动作可使用经过筛选的图标库，但品牌入口和核心教学动作应使用自定义符号。文字足够清楚时不添加图标。

## AI 生图适用范围

适用：

- 首页/课程专题封面；
- 低对比背景纹理；
- 内容类别插画；
- 图标概念探索。

不适用：

- 需要事实准确的教学插图；
- 未经专家审查的文化服饰、宗教或地理表达；
- 数据图表；
- 重要 UI 文案；
- 把真实儿童照片“生成化”。

## 资产门禁

- prompt 和参考来源登记；
- 无可识别真实未成年人；
- 无商标和未经许可的角色；
- 教研/文化审查；
- 对比度和裁切测试；
- 体积预算；
- 响应式和暗/浅背景版本；
- 原始生成文件不直接作为最终生产图标。
