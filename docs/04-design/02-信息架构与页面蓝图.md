# 信息架构与页面蓝图

## 学生端

主导航最多四项：

1. 今日
2. 课程
3. 进度
4. 我的

### 今日页

- 顶部不是统计卡，而是“一件最重要的事”；
- 继续学习形成路径式主构图；
- 网络/同步状态是安静但清楚的系统信息；
- 已完成内容收起，不与待办争夺注意；
- 无任务时给出解释和可行动入口。

### 学习页

- 内容是主角，导航和装饰退后；
- 视频、音频、文本、练习保持一致的活动框架；
- 进度、保存、离线和提交状态持续可见；
- 语音反馈使用局部波形/对齐标记，不做娱乐化“大评分”。

## 教师端

主导航：

1. 工作台
2. 班级
3. 任务
4. 内容
5. 报告

工作台优先展示：

- 待复核；
- 未完成/同步异常；
- 近期截止；
- 班级共性困难；
- 快速布置任务。

数字本身不占据首屏，数字必须指向可执行动作。

## 教研端

采用“编辑工作室”而非后台表格：

- 左侧课程结构；
- 中部活动编辑画布；
- 右侧属性/校验；
- 审核、版本和资源版权清楚可见；
- 预览学生体验。

## 管理端

采用“运营与治理台”：

- 学校成员和权限；
- 使用与同步健康；
- 内容和数据治理；
- 审计和导出；
- 不需要艺术化大 Hero，但保留品牌排版和地形线微纹理。
