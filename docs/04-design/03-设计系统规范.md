# 设计系统规范

## 目标

GOV-004 建立的是所有端通用的基础设计语言，而不是某一页的视觉包装。品牌母题只在节奏、边界、焦点和状态中出现：

- 学习路径与地形线：强调方向、分层和进度，不制造卡片海。
- 语言与声波：强调节奏、反馈和运动，不依赖夸张背景和装饰插画。

本层只定义 token 与基础原语，不定义业务布局、角色专属组件或页面专用皮肤。

## Token 分层

### Primitive tokens

只承载原始设计数值：

- 原始色值：米白、墨黑、酒红、草绿、暖金，以及 success / warning / danger / information 的最小状态底色与前景色；
- 字体与字号：正文、展示标题、字重、行高；
- 间距：从 4px 到 96px 的基础比例；
- 圆角：sm / md / lg / xl / pill；
- 阴影：仅用于浮层和按压层级；
- 动效：fast / base / slow 与标准缓动；
- z-index：base / sticky / overlay / toast；
- 响应式基线：移动、平板、桌面断点与内容宽度。

约束：

- 不直接用业务命名；
- 不为单页制造一串相近色值；
- 不在 token 中嵌入图片、路径和页面资产；
- 所有数值都需要可解释，避免无文档 magic number。

### Semantic tokens

在 primitive 之上统一命名：

- `background`: `canvas` / `canvas-strong` / `muted` / `elevated` / `contrast` / `brand`
- `surface`: `default` / `subtle` / `raised` / `contrast` / `brand`
- `text`: `primary` / `secondary` / `muted` / `contrast` / `on-brand` / `accent`
- `border`: `subtle` / `default` / `strong` / `contrast`
- `action`: `primary` / `secondary` / `link`
- `focus`: `ring` / `shadow`
- `success` / `warning` / `danger` / `information`

语义层是各端协作的主要接口。业务代码不得绕过语义层直接写任意 hex。

### Component tokens

只允许基础原语在局部 CSS 变量中定义必要 token，例如：

- `--yx-button-*`
- `--yx-link-*`
- `--yx-input-*`
- `--yx-status-*`

禁止：

- `dashboard-card`
- `course-card`
- `student-panel`
- `hero`
- `sidebar`

业务组合留在 Feature 层，不进入 `@yuzan/ui` 通用包。

兼容策略：

- 旧 `--yx-color-*`、`--yx-text-*`、`--yx-space-*` 仅作为迁移别名保留；
- 新原语只允许依赖新的 semantic token；
- 迁移完成后，兼容别名应逐步下线，不继续扩张别名族。

## 颜色与对比度

- 主内容使用浅米色画布与高对比墨色文字；
- 品牌色酒红只承担动作、强调和路径节点，不负责所有背景；
- 辅助绿色只承担恢复、进度和自然缓冲，不变成大面积“后台通用绿”；
- 状态颜色必须同时提供前景、背景和边框，而不是只改文字颜色；
- 正文字色与关键控件需满足 WCAG AA；
- 焦点与边界必须在浅底、深底和品牌底上都能辨认。

明确禁止：

- 紫蓝渐变
- 玻璃拟态
- 高饱和霓虹
- 把所有模块都做成 surface 卡片

## 排版

- 正文从 16px 起步，优先稳定、授权清晰的中文字体栈；
- 展示标题可以更强，但必须保证多端可读；
- 大标题使用更紧的行高，正文使用 1.6 至 1.75 的阅读行高；
- 触控目标至少 44 x 44 CSS px；
- 长文本保持合理行宽，阅读列宽控制在 `--yx-content-reading`。

## 圆角、阴影与空间

- 圆角表达材料层级，不是默认装饰；
- 同一视图尽量控制在 2 到 3 个圆角层级；
- 阴影只在浮层、悬浮和按压态出现；
- 分隔优先用留白、边界和节奏，而不是卡片套卡片；
- 间距使用统一比例，避免每个组件自造一套节奏。

## 动效与 Reduced Motion

- 动效只服务于状态变化、路径推进、保存反馈和空间关系；
- 默认动画时长控制在 120ms 到 320ms；
- `prefers-reduced-motion: reduce` 时，持续动画和过渡需降到近乎静止；
- loading 状态不能只靠旋转或闪烁表达，必须有文本语义。

## 主题范围

本任务不建立完整 dark mode，只要求：

- 基础组件在浅色页面正常工作；
- 在深色或品牌色背景上有 `contrast` 可选 variant；
- 不依赖 `prefers-color-scheme` 自动切整站主题；
- 不预埋一套暂时无人维护的深色产品皮肤。

## 基础原语 API 范围

### `YxButton`

- `kind`: `primary | secondary | quiet`
- `surface`: `default | contrast`
- `type`: `button | submit | reset`
- `disabled`
- `loading`
- `loadingLabel`

要求：

- loading 时提供明确文本；
- disabled 和 loading 都不可触发；
- 焦点可见；
- reduced motion 生效。

### `YxLink`

- 保持原生 `<a>` 语义；
- `href` 必填；
- `target` / `rel` 由调用方显式决定；
- `tone`: `default | muted | accent`
- `surface`: `default | contrast`

要求：

- 下划线始终存在，不只靠颜色；
- 不能伪装成按钮。
- 当 `target="_blank"` 时，调用方必须同时显式传入安全 `rel`，例如 `noopener noreferrer`。

### `YxInput`

- `label`
- `id`
- `modelValue`
- `type`
- `description`
- `error`
- `required`
- `disabled`
- `readonly`
- `surface`

要求：

- `label` 与控件显式关联；
- 支持 `aria-invalid`；
- 自动拼接 `aria-describedby`；
- 错误文本使用 `role="alert"`；
- 焦点和边界在深浅背景都可辨识。

### `YxStatus`

- `tone`: `neutral | success | warning | danger | information`
- `surface`: `default | contrast`

要求：

- 只承担语义状态展示；
- 不演变为复杂徽章系统；
- 状态含前景、背景、边界三要素。
- 默认不承担 assertive live region；如需即时播报，应由更高层语义容器明确提供。

## 验收要求

基础组件至少覆盖以下矩阵：

- `default`
- `hover`
- `focus-visible`
- `active`
- `disabled`
- `loading`
- `error`
- `dark-surface variant`

并且必须完成：

- 1440 / 1024 / 390 视口检查；
- Tab 顺序、Enter / Space 与 disabled 行为检查；
- reduced motion 检查；
- 对比度检查；
- 明暗背景下的焦点和边界检查。

若项目暂时没有独立组件展示环境，可在 `design-lab/reviews/` 维护轻量本地预览，但不得将其作为生产页面。

如果预览无法通过真实浏览器在目标视口下导出截图，则只能作为视觉图板证据，不得替代真实浏览器级键盘、响应式和可访问性终验。
