# 可观测性与运维

## 三类信号

### Logs

结构化 JSON：

- timestamp
- level
- service
- request_id
- trace_id（启用时）
- school_id（脱敏/必要时）
- actor_id（不可使用姓名）
- event
- duration_ms
- error_code

禁止记录密码、token、完整请求体、原始音频和学生敏感字段。

### Metrics

- 请求量、错误率、P50/P95；
- 数据库连接和慢查询；
- worker 队列深度/失败/重试；
- 同步成功、冲突和积压；
- 语音任务耗时和失败；
- 内容包构建/下载；
- 关键业务转换率。

### Traces

在 API—worker—对象存储—模型调用链需要排障后启用，不为“技术栈齐全”而强行加入。

## 健康检查

- `/health/live`：进程存活；
- `/health/ready`：数据库和必要依赖可用；
- 不将昂贵外部 AI 供应商作为 API readiness 的硬阻塞；
- worker 有独立健康和积压指标。

## 发布

- 数据库迁移先在 staging 演练；
- 小步、可回滚；
- feature flag 控制语音和离线新能力；
- 发布后自动 smoke test；
- 重大故障有降级：关闭 AI 不影响基本任务学习和教师反馈。
