# 安全、隐私与未成年人数据

## 数据最小化

MVP 默认不收集身份证、精确地址、民族、家庭经济情况等高敏感字段。每个新增字段必须记录：

- 业务目的；
- 法律/授权依据；
- 使用角色；
- 保留期限；
- 是否进入导出/报表；
- 删除和更正方式。

## 身份与会话

- 密码使用现代自适应哈希；
- JWT/会话密钥只能来自 secret manager/环境；
- 短期访问令牌 + 可撤销刷新会话；
- 登录、重置、导出和高风险操作限流；
- 管理操作支持 MFA（试点后按风险开启）；
- CORS 使用明确允许列表；
- Cookie 场景启用 Secure/HttpOnly/SameSite 与 CSRF 防护。

## 文件与音频

- 文件头与 MIME 双重检查；
- 病毒/恶意内容扫描；
- 对象存储私有桶；
- 短期签名 URL；
- 音频保留期限和删除策略；
- 不将原始音频写入普通日志或分析事件。

## 多租户和授权

- 所有服务层查询带学校范围；
- 对象存储 key 也按租户隔离；
- 关键路径做跨租户负向测试；
- 支持对异常管理员访问进行审计。

## 安全门禁

- SAST、依赖漏洞、secret scan；
- OWASP API 风险测试；
- 上传、IDOR、越权、速率限制；
- 备份恢复；
- 日志脱敏；
- 安全事件响应联系人和流程。

正式试点前必须由具备资质的法律/安全人员结合部署地区和实际数据重新审查。
