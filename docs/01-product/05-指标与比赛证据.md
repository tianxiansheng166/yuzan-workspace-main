# 产品指标与比赛证据

## 北极星指标

不使用“注册人数”和“页面访问量”作为唯一成果。首期北极星指标：

> 在弱网场景中，按时完成并获得有效反馈的任务比例。

## 产品指标

### 学生

- 今日任务启动率；
- 任务完成率；
- 离线完成成功率；
- 提交同步成功率及 P95 时间；
- 获得教师反馈的中位时间；
- 复学/连续使用不是强制游戏化，而看真实周留存。

### 教师

- 创建任务耗时；
- 每周需要人工复核的提交比例；
- 干预队列处理完成率；
- 报表带来实际教学动作的比例；
- 内容复用次数。

### 内容

- 课程审核通过率；
- 发布版本缺陷率；
- 资源版权完整率；
- 离线包构建成功率；
- 课程被实际布置和完成的比例。

### 技术

- API 成功率和 P95；
- 同步冲突率、重复写入率；
- 弱网下首屏与活动可用时间；
- 语音任务处理时间、失败率；
- 自动评分与教师评分的一致性及分组差异。

## 比赛证据链

每个技术亮点都使用：

```text
真实约束 → 设计选择 → 实现 → 测试方法 → 量化结果 → 用户结果 → 局限与下一步
```

禁止：

- 把模型宣传参数当项目实测；
- 把页面截图当技术落地证据；
- 用“AI 精准识别”“万人并发”等无法复核的措辞；
- 伪造合作、用户、论文、专利或试点数据。
