# 语赞心声｜学生任务中心（独立还原包）

这是一个**不写入原项目**的独立静态网页还原包，对应学生端「任务中心」页面。

## 文件结构

- `index.html`：页面结构
- `styles.css`：视觉样式与响应式布局
- `app.js`：任务列表渲染与交互逻辑
- `assets/`：Logo 图案、背景图、课程封面等独立素材
- `scripts/screenshot.py`：Playwright 截图脚本
- `qa/`：浏览器截图输出目录

## 实现原则

- 不将整张参考图直接作为网页背景。
- Logo 只使用图案部分，中文文字改为真实前端文本排版。
- 导航、按钮、任务卡片、状态、进度条、建议面板、学习小贴士、本地任务状态等均使用真实 HTML/CSS/JS 实现。
- 背景插画拆分为独立装饰素材，按区域使用，并做柔化与弱化处理，避免与交互区产生突兀色差。

## 使用方式

直接打开 `index.html` 可预览。

如果本地环境装有 Playwright（Python 版）与 Chromium，可运行：

```bash
python scripts/screenshot.py
```

生成桌面端、平板端、移动端截图。
