# 语赞心声｜学生任务中心独立还原包

本目录是独立静态网页，不写入现有项目。

## 结构

- `index.html`：真实页面结构
- `styles.css`：桌面、平板、手机响应式样式
- `app.js`：任务筛选、开始任务、离线状态、展开任务等交互
- `assets/`：独立 Logo 图案、课程封面、装饰性地形素材
- `qa/`：浏览器截图、差异图和校准报告
- `scripts/screenshot.py`：Playwright 浏览器截图脚本

## 预览

直接打开 `index.html`。页面不依赖构建工具和网络资源。

## 实现边界

导航、任务内容、截止时间、预计时长、完成标准、教师建议、本地草稿、待同步、已完成状态均为真实 HTML/CSS/JavaScript；没有把整张参考图作为页面背景。Logo 只使用图案，品牌文字由 HTML 排版。
