# 一对一公益帮扶展示页｜独立网页交付

## 打开方式
解压后直接打开 `index.html`。

## 实现说明
- 不写入原项目，所有文件都在本目录内。
- 参考分辨率：1672 × 941。
- 左侧导航、标题、流程、业务说明、登录和申请交互均由 HTML/CSS/JS 重建。
- 左上角使用提供的 Logo 图案，品牌文字由 HTML 渲染。
- 顶部山脊仅作为远景窄幅装饰，已进行横向裁切、降饱和、提亮、轻微虚化与透明渐隐。
- 人物插画仅作为解释业务关系的静态插画层，未将按钮、动态文字或业务数据烘焙进背景图。
- 额外背景素材没有为了“放全”而强行堆入页面，只保留适合当前空间职责的部分。

## 交互
- 左侧导航状态切换。
- 帮扶流程节点点击/键盘聚焦反馈。
- 志愿者登录弹窗。
- 立即申请弹窗。
