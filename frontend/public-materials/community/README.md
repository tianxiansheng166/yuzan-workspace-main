# 语言实践社区 - 静态还原包

## 运行方式

直接打开 `index.html`，或在当前目录执行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080
```

## 文件说明

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：基础交互
- `assets/`：Logo 图案、山脉背景、话题河流装饰、卡片缩略图等素材
- `qa/`：当前截图、对比图、差异图

## 页面实现说明

- 页面为独立静态还原包，没有写入原项目。
- 左侧导航、搜索框、精选作品卡片、主题活动、社区规范、参与方式、线下活动等均为真实 HTML/CSS/JS 结构。
- 山脉、路径河流、纸张纹理等视觉元素作为独立装饰素材分区使用，没有把整张参考图直接铺成网页背景。
- 已附带 `qa/current.png`、`qa/side-by-side.jpg`、`qa/diff.png` 方便继续校准。
