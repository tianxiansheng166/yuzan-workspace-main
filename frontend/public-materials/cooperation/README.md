# 语赞心声｜学校合作方案独立网页

这是一个不写入现有项目、解压即可运行的静态网页包。

## 文件
- `index.html`：页面结构
- `styles.css`：桌面、平板、移动端样式
- `app.js`：方案选择、导航和咨询表单状态交互
- `assets/`：从用户提供素材中裁切、调色和渐隐处理的运行资产
- `reference/`：原始参考图与说明材料

## 图片使用原则
- 顶部山景被裁成横向远景带，并降低饱和度、对比度与不透明度；没有为了放全图片而挤压页面。
- 课堂插画只作为首屏右侧场景说明，左侧渐隐后与文本工作区融合。
- 左侧深蓝导航底部只使用经过提线和染色的山形线稿，不直接塞入高饱和整图。
- 其他背景素材保留在 `reference/`，没有强行放进业务区域。
- Logo 仅使用用户提供图案部分，品牌文字由 HTML 渲染。

## 打开
直接双击 `index.html`，或在目录运行：

```bash
python -m http.server 8080
```
