# 一对一帮扶管理｜独立高保真网页

本压缩包为独立静态交付，不写入原项目。

## 打开方式

直接打开 `index.html`。浏览器限制本地资源时，在目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 资产处理

- 左上角图案从用户提供的 Logo 中提取，品牌文字由 HTML 渲染。
- 页眉山水使用用户提供的横向山水图，经过横向裁切、降饱和、提亮、轻微柔化以及左侧/底部渐隐处理，只作为页眉远景。
- 左侧底部红色山川使用用户提供的纵向山谷图裁切，经过渐隐和色彩统一，仅放置于侧栏底部。
- 学生姓名、按钮、阶段计划、沟通记录和业务状态全部使用 HTML/CSS 渲染，不烘焙进图片。

## 交互

包含学生切换、流程阶段切换、导航状态、教师联系、预约沟通、风险标记、结束帮扶和弹窗反馈。
