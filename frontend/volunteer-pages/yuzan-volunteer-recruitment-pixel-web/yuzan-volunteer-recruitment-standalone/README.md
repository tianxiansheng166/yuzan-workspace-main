# 语赞心声｜志愿者招募独立网页

这是一个不写入原项目、解压即可运行的静态网页包。

## 使用

直接打开 `index.html`。若浏览器限制本地脚本，可在目录中运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 资产使用说明

- Logo：仅从用户提供的 Logo 中提取图案，中文品牌文字由 HTML 渲染。
- 顶部山景：只截取山脊区域，拉成长条后做了降饱和、提亮、轻微虚化和渐隐处理，避免与白色导航区产生明显色差。
- 右侧人物插画：仅作为首屏流程图的解释性插画，裁切后与左侧内容渐隐融合，没有为了展示完整图片而压缩布局。
- 左下山景：使用参考页对应构图，仅作为导航背景，不承载按钮和动态文本。
- 其他大图保留在 `reference/`，没有强行塞进页面。

## 交互

- 服务方向切换会更新培训时长和时间投入。
- “申请加入”打开真实 HTML 表单，包含提交中和提交成功反馈。
- 支持桌面、平板和移动端布局。
