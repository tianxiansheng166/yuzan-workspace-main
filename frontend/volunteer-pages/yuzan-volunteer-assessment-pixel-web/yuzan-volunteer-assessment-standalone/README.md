# 语赞心声｜志愿者培训考核独立网页

这是一个不写入任何项目、解压即可直接打开的静态网页包。

## 内容

- `index.html`：页面结构
- `styles.css`：桌面与响应式样式
- `app.js`：题目选择、标记、提交等轻交互
- `assets/`：基于用户提供素材整理的运行资产
- `reference/`：原始参考图、提示词和说明文件

## 说明

- Logo 仅使用用户提供的图案部分，品牌文字由网页文本渲染。
- 右上角山水图直接采用用户给定素材。
- 左下侧栏山地装饰取自用户提供的竖版背景图。
- 题目导航、单选作答、标记、自动保存提示和提交按钮均为 HTML/CSS/JS 重建，可继续接入真实数据。

## 打开方式

直接双击 `index.html` 即可。

若本地浏览器限制脚本，可在当前目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。
