【艺术方向】
- 视觉中心必须是当前业务的核心路径或核心工作对象，不是统计数字。
- 使用高原红承担主行动和公益连接；青稞绿承担完成和成长；深夜藏蓝承担技术与稳定；雪山灰白承载阅读；路径金只做连接高光。
- 背景需要有层次：近景为可工作的 UI 画布，中景为地形线/声场/路径，远景为极克制的山脊或纸张纹理。
- 插画只在能解释业务关系时出现，不得占据主要操作区。
- 设计应有成熟教育产品的精密秩序，也保留援藏公益项目的人情温度。

【前端实现边界】
用户和权限必须来自真实安全模型，不使用虚构角色。
- 真实姓名、学校、班级、数量、成绩、报告、权限、登录状态、链接、二维码、表单值、AI 结果和同步状态必须由真实数据与前端代码渲染。
- 按钮、输入框、导航、表格、筛选、弹层、可访问状态必须用 Vue/HTML/CSS 重建，不能从图片裁切。
- 参考图中的任何假数据均不得进入生产。
- 不得因为视觉图改变既有 API、权限、租户隔离、离线语义或真实状态机。
