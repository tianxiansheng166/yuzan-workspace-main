# 测评链接与二维码管理｜交付说明

## 页面信息
- 路由建议：`/admin/assessment-links`
- 页面类型：管理端 / 测评链接与二维码管理
- 交付形式：独立静态网页包，不写入现有项目

## 已实现内容
- 顶部品牌栏、右侧通知与用户区
- 左侧管理后台导航，含当前激活态
- 中央“链接生命周期”工作流轨道
- 筛选区：搜索、学校、状态、时间范围、重置、新建链接
- 主表格：链接名称、学校/班级、测评对象、有效期、身份策略、访问/完成、状态
- 右侧详情面板：链接信息、二维码预览、复制、下载、重新生成、停用、导出
- 下方数据区：异常访问趋势、异常访问总数、异常任务数、占总访问比例、异常类型分布
- 响应式布局：桌面、平板、手机

## 主要交互
- 点击表格行切换右侧详情
- 搜索与筛选即时过滤
- 标签页切换“链接信息 / 二维码预览”
- 复制链接、重置筛选、重新生成、停用、导出提供 Toast 反馈
- 手机端支持菜单抽屉

## 视觉实现说明
- Logo 仅保留图案头部，标题与后台名称使用 HTML 文字重建
- 山脊与路径背景作为独立素材放置在生命周期卡片右侧
- 主操作区全部使用 HTML/CSS/JS 重建，没有把整张参考图直接盖到页面上
- 用留白、细边框和弱纹理控制色差，避免背景素材抢占主交互区

## 文件结构
- `index.html` 页面入口
- `styles.css` 样式
- `script.js` 页面数据与交互
- `assets/` 图片与二维码素材
