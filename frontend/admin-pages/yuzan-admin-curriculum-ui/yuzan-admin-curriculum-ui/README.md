# 课程内容治理中心｜独立静态还原包

这是一个不依赖原项目的独立网页还原包，面向课程管理后台页面的高保真前端参考实现。

## 文件结构

- `index.html`：页面结构
- `styles.css`：样式与响应式布局
- `app.js`：交互逻辑与示例状态
- `assets/`：独立素材（Logo 图案、山脊装饰、预览插画）
- `qa/`：Playwright 截图、参考图、差异图和校准报告
- `asset-usage.json`：页面资产说明
- `start.sh` / `start.bat`：本地启动脚本

## 还原原则

- 动态 UI 均用 HTML / CSS / JavaScript 重建
- Logo 只保留图案，文字用网页文本渲染
- 装饰山脊、纸张纹理、预览插画为独立生产候选素材
- 没有把整张参考图直接当网页背景
- 管理端采用高密度、低装饰度的治理工作台表达

## 演示交互

- 搜索课程名称或编码
- 点击课程行切换右侧详情
- 发布按钮打开确认弹窗，并可切换状态
- 下线按钮可切换为停用状态
- 移动端抽屉侧栏

## 启动方式

### macOS / Linux

```bash
bash start.sh
```

### Windows

双击 `start.bat`，或在命令行运行：

```bat
start.bat
```
