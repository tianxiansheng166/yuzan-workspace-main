# 语赞心声｜教师测评详情像素级还原

## 使用

直接双击 `index.html` 即可打开；也可在本目录启动任意静态服务器。

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 文件

- `index.html`：页面结构
- `styles.css`：完整桌面/平板/移动端样式
- `app.js`：筛选、搜索、阶段切换、弹窗、暂停等交互
- `assets/`：用户提供的品牌和背景素材及其网页适配衍生图
- `reference.png`：原始页面参考图，仅用于视觉核对，不参与页面渲染

## 说明

页面未把参考截图整张作为背景，导航、按钮、表格、图表、文本和交互均由 HTML/CSS/SVG 重建。
