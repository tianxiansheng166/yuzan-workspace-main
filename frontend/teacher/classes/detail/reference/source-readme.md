# 教师班级详情与学情地图｜V3.1

- 页面族：教师端
- 建议路由：`/teacher/classes/:classId`
- 主要使用者：负责该班级的教师
- 生图文件：`prompt.md`
- 图片目录：`images/`
- 推荐候选：2–3 张
- 输出比例：16:9 桌面端
- 资产分类：页面级设计参考图

## 手动使用

1. 将本目录 `prompt.md` 完整复制给具有生图能力的 Codex/GPT。
2. 同时上传提示词列出的母版参考图。
3. 每次只生成一张完整页面，不生成拼贴或设计说明板。
4. 图片生成后直接放入 `images/`，不需要手动改名。
5. 多张候选都可保留，后续由多模态 Codex 选择、重命名并写资产清单。
6. 不要把原始图片直接复制到 `apps/web`。
7. 前端实现时必须用真实 Vue/HTML/CSS 重建动态 UI。

## 本页验收重点

- 页面视觉中心是否围绕“把班级整体学习状态、学生差异和教学行动放在同一张可下钻的学情地图中，帮助教师决定下一节课和下一次干预。”
- 是否避免卡片墙、整页暖黄、紫蓝 AI 渐变与玻璃拟态
- 是否能看出援藏教育公益属性，但没有旅游化表达
- 是否保留了清晰的真实交互区和动态数据区
- 是否能被 1440px、768px、390px 三种布局重建
