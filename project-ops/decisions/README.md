# decisions

当前相关决策文档已存在于仓库其他位置：

- `docs/ADR/`：正式架构决策记录
- `orchestration/AI-COLLABORATION-PROTOCOL.md`：多 AI 协作协议
- `orchestration/CONTRACT-FIRST.md`：契约优先规则
- `orchestration/INTEGRATION-GATES.md`：集成门禁
- `orchestration/CODE-REVIEW-RUBRIC.md`：代码审查标准

新增决策时，优先在 `docs/ADR/` 创建，并在此登记索引。
