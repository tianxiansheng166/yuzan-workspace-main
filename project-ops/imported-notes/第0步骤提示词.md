C:\yuzan-workspace\legacy\source-tree\two-legacy

1. 新项目正式开发目录是：

C:\yuzan-workspace\yuzan-next

5. 若遇到需要用户点击、管理员权限、重启、启用 WSL2、启用虚拟化或启动 Docker Desktop，停止当前危险操作并明确报告。

二、先检查路径
━━━━━━━━━━━━━━━━━━━━

在 PowerShell 中执行：

Set-Location "C:\yuzan-workspace"

$RequiredPaths = @(
"C:\yuzan-workspace\AI-OPERATOR",
"C:\yuzan-workspace\orchestration",
"C:\yuzan-workspace\orchestration\scripts\prepare\_workspace.ps1",
"C:\yuzan-workspace\orchestration\scripts\prepare\_wave0.ps1",
"C:\yuzan-workspace\yuzan-next",
"C:\yuzan-workspace\yuzan-next\package.json",
"C:\yuzan-workspace\legacy\source-tree\two-legacy"
)

$RequiredPaths | ForEach-Object {
\[PSCustomObject]@{
Path = $\_
Exists = Test-Path $\_
}
}

如果其中任何一项为 False，停止并报告 ENVIRONMENT\_BLOCKED。

Get-ExecutionPolicy -List

本次进程如果无法执行本地脚本，只为当前 PowerShell 进程临时执行：

不得修改整个系统或当前用户的永久执行策略。
