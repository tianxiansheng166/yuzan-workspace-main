# 安全自主执行边界

允许 AI 在已通过 preflight 的任务 worktree 内自主：

- 在 `allowed_paths` 中选择最小、可逆实现；
- 读取 `context.required` 与直接相关源码；
- 运行任务声明的局部验证；
- 修复验证暴露的同范围问题；
- 完成自审、handoff 和本地提交；
- 在任务明确授权时推送自己的 task branch。

禁止未经明确授权执行：

- `git reset --hard`、`git clean -fdx` 或强制推送；
- 删除未备份数据库、Docker volume 或其他任务未提交工作；
- 修改任务白名单外的共享文件；
- 提交密钥、真实学生数据和来源不明资产；
- 批量终止无关进程或删除项目外目录。

普通实现不确定性不需要停下征询；选择最小可验证方案并记录假设。遇到会改变产品
方向、共享契约/schema、权限边界、数据解释、他人工作或外部生产状态的冲突时，
停止扩展并提交决策/CCR 请求。
