# project-ops: 多机器、多 AI 协作真源

本目录（`project-ops/`）是语赞心声 `yuzan-next` 项目跨物理机、跨 AI 代理协作的**运营真源（source of truth）**。

## 真源优先级

在出现任何描述不一致时，以下优先级从高到低：

1. **代码事实**：以 `main` 分支上的实际提交为准。
2. **任务状态**：以本目录下的 `TASK-REGISTRY.yaml` 为准。
3. **分支状态**：以 Git 仓库实际分支和 worktree 为准。
4. **机器归属**：以 `MACHINE-REGISTRY.md` 为准。
5. **协作规则**：以 `MULTI-MACHINE-PLAYBOOK.md` 为准。

**不要以某个聊天窗口、某次会话或某个 AI 的口头描述作为最终事实。** 所有状态变更必须通过提交进入版本管理。

## 目录说明

| 目录               | 用途                                                 |
| ------------------ | ---------------------------------------------------- |
| `runtime-prompts/` | 已分派给 AI 的正式任务提示词                         |
| `runtime-reports/` | 任务执行、审查、集成的正式报告                       |
| `imported-notes/`  | 从外层工作区迁移进来的协作说明、检查清单和历史提示词 |
| `decisions/`       | 架构决策、集成门禁和协作协议                         |
| `handoffs/`        | 任务交接模板与已完成的交接记录                       |

## 使用约束

- 本目录只存放运营、协作、审计类文本资料。
- 不存放产品代码、OpenAPI、Prisma schema、UI token 或业务逻辑。
- 不存放 `.env`、密钥、私钥、数据库、MinIO 数据或构建产物。
- 不存放 `legacy/source-tree/` 或 worktree 的完整副本。
- 所有纳入文件必须通过隐私和敏感信息扫描。
